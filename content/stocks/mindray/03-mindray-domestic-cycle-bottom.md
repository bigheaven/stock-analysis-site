# 迈瑞医疗（300760.SZ）· 国内 To G 周期底研判

> **免责声明**：本文为基于公开信息的综合分析，**不构成任何投资建议**。所有结论含主观判断，投资决策与风险由读者自担。
>
> **数据截止日期**：2026-07-05（当前价 ~140 元）
>
> **信息来源**：迈瑞 2024/2025 年报、2026 Q1 季报、21经济网、新华网、财经、证券时报、国投证券招采数据、东吴证券研报等。详见文末引用源。

## 一、核心命题

> **国内业务（2025 -22.97%、2026 Q1 -11.13%）何时见底？公司"2026 国内正增长"指引能否兑现？**

这是判断迈瑞业绩拐点的关键。用户假设"龙头恢复快"——但国内的问题不是份额（份额在涨），而是整个需求池在周期性收缩。本报告用先行 + 滞后双轨指标判断周期底。

## 二、迈瑞的"To G 属性"——为什么国内是周期问题

```
迈瑞国内业务的 To G 本质
═══════════════════════════════════════════════════════
  医院采购预算 ─┬─ 医疗专项债发行
                ├─ 地方财政资金
                ├─ 医疗新基建项目
                └─ 设备更新专项资金
                        │
                        ▼
  与人口/财政周期同步 ≈ "地产不兴，股价不起"
  （2024 年报坦言：医疗专项债连续两年下滑致新基建延误）
```

**关键认知**：迈瑞国内不是纯 To B 消费品，而是与地方财政、医疗基建周期高度相关。这意味着国内见底不取决于迈瑞自身，而取决于医疗财政周期的拐点。

## 三、需求池压缩——周期性 vs 结构性

```
┌─────────────────────────────────────────────────────────────┐
│  压缩因素              │ 性质      │ 量级/方向  │ 可恢复？  │
├─────────────────────────────────────────────────────────────┤
│  医疗反腐(2023起)      │ 周期      │ 招标停滞   │ ✅ 可恢复 │
│  医疗专项债下滑        │ 周期      │ 新基建延误 │ ✅ 可恢复 │
│  设备更新周期结束      │ 周期      │ 透支需求   │ ⚠️ 慢恢复 │
│  床位首减 28 万张      │ 周期/结构 │ 5年扩张结束│ ⚠️ 慢恢复 │
│  DRG/DIP 改革          │ 结构      │ 控费常态   │ ❌ 不可逆 │
│  检验结果互认          │ 结构      │ 检测量↓   │ ❌ 不可逆 │
│  医疗服务价格治理      │ 结构      │ 检查费↓   │ ❌ 不可逆 │
└─────────────────────────────────────────────────────────────┘
周期性因素占主导 → 国内业务可恢复，但结构性因素压低新中枢
```

**设备更新周期细节**：上一轮 5 年医疗新基建扩张期，医院已大规模"以旧换新"；设备标注寿命 5 年但实际用 8—10 年，意味着大规模更新需求收缩。2024 年四部委《设备更新实施方案》提"2027 年较 2023 年设备投资 +25%"，但 2024 招标落地比例低，剩余部分 2025—2026 陆续落地。

## 四、先行 + 滞后双轨指标体系

### 先行指标（领先业绩 6—12 个月）

```
┌──────────────────────────────────────────────────────────────┐
│  指标                  │  状态(2026 初)      │  信号         │
├──────────────────────────────────────────────────────────────┤
│  医疗专项债发行额      │  2026Q1 同比快增    │  ✅ 转正      │
│  设备更新招标披露额    │  2024-12 起持续改善 │  ✅ 转正      │
│  迈瑞中标额            │  2025-12至2026-02   │  ✅ +12%      │
│                        │  +12%(国投证券)     │               │
│  医疗新基建审批额      │  待 200 亿待释放    │  ✅ 在途      │
└──────────────────────────────────────────────────────────────┘
```

### 滞后确认指标

```
┌──────────────────────────────────────────────────────────────┐
│  指标                  │  状态               │  信号         │
├──────────────────────────────────────────────────────────────┤
│  迈瑞国内收入          │  2026Q1 -11.13%     │  ⚠️ 仍负但收窄│
│  生命信息与支持(设备)  │  2026Q1 信息支持-5.86%│ ⚠️ 收窄     │
│  医学影像              │  2026Q1 -11.83%     │  ⚠️ 仍承压   │
│  医疗机构床位数        │  2025 首减 28 万张  │  ❌ 结构性   │
│  医院采购预算          │  仍普遍承压         │  ⚠️ 弱复苏   │
└──────────────────────────────────────────────────────────────┘
```

**先行指标已转正，滞后指标仍负但收窄**——这是典型的"周期底前夜"信号组合。先行指标转正后 6—12 个月，滞后指标（业绩）通常跟进。

## 五、见底时点概率判断

```
见底时点概率（国内业务同比转正）
═════════════════════════════════════════════════════
  2026 年内见底（公司指引"2026 国内正增长"）
  概率：40%
  触发：专项债发力 + 设备更新落地 + Q3/Q4 单季转正
  风险：Q1 仍 -11.13%，全年转正需 H2 强反弹
  
  2027 年见底
  概率：45%（基准情景）
  触发：2026 全年仍微负，2027 低基数 + 周期复苏转正
  依据：先行指标 2026 初转正 → 业绩 2027 兑现
  
  2028 年及以后
  概率：15%
  触发：结构性因素主导，新中枢低于预期
═════════════════════════════════════════════════════
```

**公司指引 vs 指标交叉验证**：公司称"2026 国内正增长、2027 后稳定快速增长"。但 2026 Q1 国内 -11.13% 已部分证伪"2026 全年正增长"的乐观解读——全年要转正，H2 需显著高于 +5% 才能对冲 Q1 的 -11%。**更现实的基准是 2026 全年国内微负或持平、2027 转正**。

## 六、确认与证伪信号

```
确认国内见底（买入右侧信号）：
  • 迈瑞单季国内收入同比转正（最快 2026 Q3/Q4）
  • 医疗专项债 2026 全年发行额同比 +20% 以上
  • 设备更新招标额持续 +25% 以上
  • 公司上调国内指引

证伪 2026 见底（继续观望）：
  • 2026 半报国内仍 -10% 以上
  • 专项债发行再度放缓
  • 床位数继续减少
  • 公司下调指引
```

## 七、国内见底判定

**结论：国内大概率 2026 年中至 2027 年见底，公司"2026 全年正增长"指引偏乐观，基准情景是 2026 收窄、2027 转正。**

先行指标（专项债、招标、中标额）已转正是最积极的信号——这意味着国内不是"无底洞"，而是有明确周期底的 To G 业务。但结构性因素（DRG/互认/价格治理）压低了新中枢，**国内业务即使见底，也很难回到 2020—2022 年的高增长**，新常态可能是中个位数增长。
