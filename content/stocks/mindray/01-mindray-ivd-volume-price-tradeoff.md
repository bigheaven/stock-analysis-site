# 迈瑞医疗（300760.SZ）· IVD 集采"以价换量"临界点深挖

> **免责声明**：本文为基于公开信息的综合分析，**不构成任何投资建议**。所有结论含主观判断，投资决策与风险由读者自担。
>
> **数据截止日期**：2026-07-05（当前价 ~140 元，PE ~21.7x）
>
> **信息来源**：迈瑞 2024/2025 年报与 2025 三季报、2026 Q1 季报、安徽集采公告、东吴证券/招商证券/浙商证券研报、新华网/证券时报/第一财经/财经/凤凰财经等。详见文末引用源。

## 一、核心命题

用户的直觉假设是"龙头 + 集采，应该恢复得快"。本报告用一道数学题回答这个假设是否成立：

> **在 2025 年安徽 28 省肿标/甲功集采平均降价 53% 的背景下，迈瑞 IVD 的装机量与试剂消耗量增速需达到多少，才能弥补单价跌幅，使收入与毛利转正？**

## 二、临界点方程

IVD 是典型的"剃刀+刀片"模式（仪器装机后持续卖试剂）。收入可分解为：

```
IVD 收入 = 装机量 × 单台试剂消耗 × 试剂单价
         └─ 量 ─┘   └── 价 ──┘

同比增速近似：
IVD 收入增速 ≈ 装机量增速 + 试剂消耗增速 + 试剂单价增速
              └─── "量"的合计 ───┘   └"价"┘
```

**关键修正：53% 是终端价降幅，不是出厂价降幅。** 集采挤压的是流通环节（经销商加价），迈瑞出厂价本来就远低于终端价，因此出厂端实际降幅远小于 53%。这是"以价换量"能否跑通的关键变量。

### 三档敏感性测算（出厂价口径）

假设 2026 集采执行首年，试剂出厂单价分别降 -20% / -30% / -40%（对应终端降幅约 -40% / -53% / -65% 的情景），倒推"装机量 + 试剂消耗"合计需达到的增速：

```
┌──────────────────────────────────────────────────────────────┐
│  出厂价降幅   │  量需增速(收入持平)  │  量需增速(毛利持平)*  │
├──────────────────────────────────────────────────────────────┤
│   -20%        │      +20%            │      +27%            │
│   -30%        │      +30%            │      +40%            │
│   -40%        │      +40%            │      +53%            │
└──────────────────────────────────────────────────────────────┘
* 毛利持平要求更高，因毛利率受压（2025 整体毛利率 60.32%，-2.79pct）
```

**分品种差异**：肿标/甲功（集采 -53%）压力最大；生化（已多次集采，边际增量小）；凝血（国产化率低，集采尚未大规模落地，弹性最大）；化学发光（迈瑞国内第三，进口替代空间大）。

## 三、先行指标：装机量

装机量是试剂收入的先行指标（领先 6—12 个月），是判断"以价换量"能否跑通的最关键领先信号。

```
2024 装机                          2025 装机                          2026 装机
═══════════                        ═══════════                        ═══════════
MT8000 流水线 ~190 套              MT8000 新增订单 360+ 套             Q1 国际新增
化学发光 1800 台(近六成高速机)      MT8000 新增装机近 270 套            TLA 订单 11 套
                                   化学发光装机持续                    国际免疫 +30%
        │                                │                                │
        └──────── 装机高增长 ────────────┴──────── 试剂收入滞后兑现 ──────┘
                  (2024)                              (2025-2026)
```

**装机量数据是 IVD 最大的亮点**：2025 MT8000 流水线新增订单 360+ 套（vs 2024 全年装机 ~190 套，翻倍），新增装机近 270 套。招商证券（香港）判断"装机量作为试剂收入的领先指标，奠定 2026—2027 IVD 较快增长基础"。

## 四、份额提升 ≠ 利润提升——关键区分

用户假设"龙头恢复快"隐含"份额提升 = 利润提升"。这个等式在集采下并不自动成立：

```
        集采落地
           │
    ┌──────┴──────┐
    ▼             ▼
 份额↑          价格↓
 10%→12%        出厂-20~40%
 肿标14%(第二)   毛利率受压
 甲功13%(第二)   2025 毛利率 -2.79pct
    │             │
    └──────┬──────┘
           ▼
   利润 = (份额 × 市场总量) × 单价 × 毛利率
           └─ 量 ─┘            └─ 价 ─┘
           
   ① 市场总量在缩(国内 IVD 池 -检验结果互认/DRG 压缩)
   ② 单价在降(集采)
   ③ 毛利率在压
   → 份额提升的利润弹性被 ①②③ 三重抵消
```

迈瑞目标 3 年将 IVD 核心业务市占率从 ~10% 提升至 20%。**份额翻倍能否转化为利润增长，取决于"市场总量缩幅 + 单价降幅"是否小于"份额提升幅度 × 毛利率韧性"。** 在国内 IVD 池萎缩（检验结果互认减少检测量）+ 集采降价的组合下，这是道紧绷的数学题。

## 五、验证窗口：2026 Q1 已部分跨越临界点（重要积极信号）

**2026 Q1 数据是本报告最重要的验证点，且方向偏积极：**

| 指标 | 2025 全年 | 2026 Q1 | 信号 |
|---|---|---|---|
| IVD 收入 | 122.41 亿（-9.41%） | 31.93 亿（**+4.96%**） | ✅ 转正 |
| 国际 IVD | +30%（2024） | **+20%** | ✅ 持续高增 |
| 国际免疫 | — | **+30%** | ✅ 装机兑现 |
| 国际新增 TLA 订单 | — | 11 套 | ✅ 装机领先指标延续 |
| 整体营收 | -9.38% | **+1.39%** | ✅ 国际对冲国内 |

**解读**：IVD 收入在 2026 Q1 转正（+4.96%），说明"装机高增长 + 国际试剂放量"已经开始跑赢国内集采降价与需求收缩。但这其中**国际 IVD（+20%）是主驱动**，国内 IVD 仍承压——即"以价换量"在国际市场率先跑通，国内仍需等待集采执行后的量价再平衡。

## 六、份额提升能否转化为利润增长的判定

**结论：能，但利润弹性远小于份额弹性，且 2026 年是验证窗口而非确认窗口。**

- **国际侧**：份额提升 + 价格平稳 → 利润弹性为正，已兑现（国际 IVD +20%、免疫 +30%）
- **国内侧**：份额提升 + 出厂价降 20—40% + 市场池缩 → 利润弹性紧绷，2026 集采执行首年是验证窗口
- **整体**：2026 Q1 IVD 转正表明临界点正在被跨越，但毛利率走向（2025 -2.79pct）仍需观察

## 七、证伪 / 证实阈值

```
证实（临界点跑通）：
  • 2026 半报 IVD 收入增速 ≥ +5%（Q1 已达标）
  • 2026 IVD 毛利率企稳或仅小幅下滑（< -1pct）
  • MT8000 装机 2026 ≥ 400 套

证伪（以价换量失败）：
  • 2026 半报 IVD 收入增速转负
  • IVD 毛利率下滑 > 3pct
  • 装机量增速骤降
```
