## 阶段一：疫情大牛市 (2020.1 → 2021.2.17)

| | |
|---|---|
| **股价** | 99 → 460 港元 (+365%) |
| **市值** | ~5,000亿 → 2.6万亿港元（中国第三大互联网公司）|

### 发生了什么

**内部**：外卖订单量因疫情宅经济激增；到店酒旅恢复超预期；新业务（优选/买菜/闪购）讲出"无边界扩张"故事，SOTP 分部估值法给每个业务线单独定价。

**外部/宏观**：全球央行大放水，港股科技股情绪极度乐观。互联网平台被视为"数字基础设施"。

**竞争**：饿了么式微（阿里本地生活多次换帅），抖音尚未入局本地生活。市场认为美团在本地生活"无敌"。

**核心叙事**："无边界扩张 + 垄断溢价 + 疫情红利"

---

## 阶段二：监管风暴 (2021.2 → 2021.8)

| | |
|---|---|
| **股价** | 460 → 249 港元 (**-46%**) |
| **市值蒸发** | 超 1.2万亿港元 |

### 发生了什么

| 日期 | 事件 | 影响 |
|------|------|------|
| 2021.4.26 | 市场监管总局对美团"二选一"立案调查 | 反垄断恐慌开始 |
| 2021.5 | 王兴发布唐诗《焚书坑》被解读为借古讽今 | 股价遭抛售 |
| 2021.7 | 七部门联合发文要求保障外卖骑手权益 | 骑手社保恐慌 |
| 2021.8.30 | Q2 财报：净亏损33.6亿，新业务半年烧掉173亿 | 商业模式受质疑 |
| 2021.10.8 | **反垄断罚款落地**：34.42亿元 + 退还12.89亿保证金 | 利空出尽 |

**叠加的外部环境**：
- 教培双减（2021.7）→ 中概股集体崩盘
- 滴滴退市（2021.12）→ 互联网监管蔓延
- 估值体系从 SOTP 切换为 PE → 亏损公司被重新定价

**核心叙事**："反垄断 + 共同富裕 + 中概股估值杀"

---

## 阶段三：震荡修复 (2021.9 → 2022.12)

| | |
|---|---|
| **股价** | 249 → 175 港元 (**-30%**) |

### 发生了什么

**内部**：反垄断罚款落地后逐步取消"二选一"，但新业务（社区团购）继续烧钱。Q3 2022 经调整净利润转正（35.9亿），基本面开始改善。

**外部/宏观**：2022年中国多城封城 → 外卖需求受益但经济整体低迷。港股恒指跌至11年低点。

**股东冲击**：2022.11 腾讯以实物分派方式减持美团（将持有股票分给腾讯股东），市场担心大量抛压。

**竞争**：抖音开始试水本地生活团购，但规模尚小，市场未充分定价此风险。

**核心叙事**："监管消化中 + 港股熊市 + 腾讯减持压制"

---

## 阶段四：过山车——抖音阴影 (2023.1 → 2024.1)

| | |
|---|---|
| **股价** | 175 → 63 港元 (**-64%**) |

### 这是美团最危险的阶段

| 日期 | 事件 | 股价反应 |
|------|------|----------|
| 2023.2.8 | 传言抖音将上线全国外卖 | 单日 **-9%** |
| 2023全年 | 抖音到店GTV ~2000亿，约占美团1/3 | 持续压制 |
| 2023.12.19 | 传言"抖音收购饿了么" | 当月 **-18.56%** |
| 2024.1.17 | **跌破69港元发行价** | 市值蒸发 **80%+** |

### 发生了什么

**竞争**：抖音凭借7亿日活，通过低价团购撬动到店业务。到店是美团利润率最高的板块（利润率 50%+），被直接攻击核心利润池。

**内部**：Q3 2023 净利润35.9亿（+195%），基本面其实在改善。但市场已不在乎——"抖音摧毁护城河"成了核心叙事。

**估值**：王兴公开说"二级市场严重低估美团，当前股价只反映了外卖单一业务的估值"。市场没听。

**核心叙事**："抖音来了，护城河没了，美团不值钱了"

---

## 阶段五：利润爆发——绝地反击 (2024.2 → 2024.10)

| | |
|---|---|
| **股价** | 63 → 183 港元 (**+192%**) |

### 发生了什么

**关键转折**：市场终于看到——抖音的冲击没有想象中大。美团到店业务在反击后守住阵地，外卖单量持续增长。

**2024年全年业绩**（引爆点）：
- 净利润 **+358亿元**（2023年为+138亿）
- 核心本地商业经营利润 **+524亿**
- 新业务亏损大幅收窄

**出海启动**：2024.9 KeeTa 进入沙特，首月表现超预期。"出海故事"开始给估值提供新的想象空间。

**核心叙事**："美团没被抖音干掉，利润反而创新高了，估值太便宜了"

---

## 阶段六：外卖大战——三英战美团 (2024.11 → 2026.7)

| | |
|---|---|
| **股价** | 183 → 83 港元 (**-55%**) |
| **当前** | 83.65 港元，市值 ~5163亿港元 |

### 发生了什么

三股力量同时进攻美团的核心地盘：

| 攻击方 | 入局时间 | 打法 | 对美团的影响 |
|--------|----------|------|-------------|
| 阿里巴巴 | 2025 | 整合饿了么+淘宝闪购+千问AI入口 | 订单量份额 74%→~65% |
| 京东 | 2025.2 | "品质外卖"（全职骑手缴五险一金） | 品质心智被分流 |
| 抖音 | 持续 | "抖省省"独立团购APP | 到店利润率持续承压 |

**美团的代价**：
```
2024全年净利：+358亿 → 2025全年净利：-234亿 （蒸发 592亿）
Q2 2025：经调整净利润暴跌 89%
Q3 2025：核心本地商业亏损 141亿
经营现金流：+57亿(2024) → -138亿(2025)
```

**2026年边际改善信号**：
- Q1 外卖单均亏损从 2元 → 1元（收窄中）
- 管理层：竞争烈度在减弱
- 华兴证券：预计 Q2 核心本地商业扭亏为盈
- LongCat-2.0 AI大模型发布（国产算力训练）

**核心叙事**："战争最惨烈的时候可能已经过去了，但什么时候真正结束还不知道"
