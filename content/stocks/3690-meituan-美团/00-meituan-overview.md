## 一、一句话定位

**中国本地生活服务绝对龙头，以700万骑手即时配送网络为护城河，覆盖外卖、到店、即时零售、出海四大战场。当前处于"外卖大战"末期，盈利修复是核心叙事。**

## 二、业务分部拆解

```
美团业务结构 (2025年报)

核心本地商业（外卖+到店+闪购）
├── 餐饮外卖          ~45%收入  百亿亏损 → 26Q2有望UE转正
├── 到店酒旅          ~18%收入  利润率最高板块（~50%→被抖音压缩）
└── 美团闪购          即时零售，连续季度盈利

新业务及其他
├── 美团优选/小象超市  食杂零售，亏损收窄中
├── KeeTa 出海        中东+拉美+香港，战略烧钱期
├── 共享单车/打车      非核心
└── 其他              快驴、金融等

收入合计 (2025): ~3,660亿元
```

## 六、主要风险

1. **竞争再度激化**：京东/阿里补贴不收敛，UE修复延后
2. **骑手社保全面强制**：300万骑手社保若被监管强制行业标配 → 单均成本+1元+，不可逆
3. **消费持续降级**：K型分化加剧，价格敏感用户流失不可逆
4. **出海受挫**：中东地缘冲突、巴西iFood强势阻击、当地监管风险
5. **AI入口替代**：千问等AI助手成为"外卖流量分配中心"，美团沦为履约方
