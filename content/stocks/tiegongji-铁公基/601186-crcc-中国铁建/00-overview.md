# 中国铁建 (601186.SH / 1186.HK) — 比中铁好一点，但好得有限

>
> **数据截止日期**：2026-07-19
>
> **相关信息**：[[crec-00-overview|中国中铁 概览]]、[[crrc-00-overview|中国中车 概览]]

## 一、一句话定位

**中国第二大铁路基建承包商（仅次于中国中铁）。同属建工行业，风险结构相同——应收款巨大、利润极薄、依赖政府回款。但分红率在提升（25.5%，+4.9pct）、经营现金流转正，比中铁边际略好。**

## 二、关键数据

```
股价：~7元 | PE 5.1x | PB ~0.24x（严重破净）
A股股息率：4.3% | H股股息率：6.4%

2025全年：
营收 10,298亿(-3.5%) | 净利 183.6亿(-17.3%)
毛利率 9.72% | 净利率 1.78%（比中铁的2.42%还薄！）
经营现金流 +29.6亿（转正！2024年为-314亿）
分红率 25.5%（+4.9pct，改善中）

新签订单 30,765亿(+1.3%) | 在手订单 45,060亿
海外新签 3,633亿(+16.5%)
```

## 四、铁建 vs 中铁：为什么铁建略好

```
同一行业，微弱的差异：

铁建更好的地方：
✅ 分红率 25.5% 且在提升（中铁 18% 停滞）
✅ 经营现金流终于转正（中铁还在挣扎）
✅ H股股息率 6.4%（中铁H仅2.6%，说明铁建H定价更合理）
✅ 海外订单增速 16.5%（中铁也在做，但没那么突出）

铁建同样糟糕的地方：
❌ 净利率 1.78%（比中铁还薄）
❌ 应收账款风险相同
❌ 依赖地方债回款
❌ 行业竞争格局一致

但如果必须在建工三巨头里选一只收息：
中车 >> 铁建 > 中铁
```

## 五、股息率可持续性

| ✅ 支撑 | ⚠️ 压力 |
|---------|---------|
| 分红率在提升(+4.9pct)，管理层有改善意愿 | 净利率仅1.78%，一个项目踩雷就能吞噬利润 |
| 经营现金流转正，不再纯靠年底回款 | 利润持续下滑(-17%)，分红增长空间有限 |
| 在手订单4.5万亿，收入高度锁定 | 应收款风险与中铁同级别 |
| H股股息率6.4%有一定安全边际 | A/H股息率差2%说明定价仍有分歧 |

## 六、底线

铁建比中铁好——分红意愿在改善、现金流在改善。但它在同一艘船上：都是建工行业、都依赖政府回款、都利润极薄。如果中铁的应收款暴雷，铁建大概率一起遭殃。

**收息选中车。非要在中铁和铁建之间选，选铁建——至少它在努力变好。**
