## 一、一句话定位

**全球最大铁路装备制造商，中国高铁100%垄断。不是成长股，是绑在铁轨上的"收租+分红"生意。当前破净（PB 0.88x）、PE 12x、股息率5.71%、Beta 0.24——A股里最像债券的股票之一。**

## 三、周期定位

用 [[cycle-growth-spectrum-framework-周期光谱框架]] 打分：

| 指标 | 状态 | 判定 |
|------|------|------|
| **渗透率** | 国内高铁5万km，新建从3000km→800km/年 | 🔴 增量收窄 |
| **CAPEX/资产** | 重资产但不像锂业疯狂扩产 | 🟡 中等 |
| **壁垒** | 国内100%垄断，全球仅4家能做350km/h | 🟢 极深护城河 |

**判定：半周期半公用事业。** 新建投资是周期（跟国铁五年规划走）；维保后市场是"收租"（400+亿/年，+25%增长）。

## 五、出海：故事很大，现实很难

```
✅ 真实进展：
├── 2025 海外新签 ~650亿 (+37%)
├── 产品覆盖 102 个国家，75个海外机构
├── 海外工厂：美国/南非/土耳其/马来西亚/印度
├── 2026世界杯：115列轻轨服务墨西哥三大城市
└── 建成：雅万高铁、中老铁路、匈塞铁路

❌ 残酷现实：
├── 真正高铁出口几乎为零（雅万是唯一）
├── 全球高铁市场仅 220亿欧元
├── 政治风险是最大拦路虎（泰国/墨西哥/伊朗均因政府更迭搁置）
├── 西门子+阿尔斯通合并抱团竞争
└── 日本用0.1%超低利率抢单

结论：出海卖得动地铁/机车/货车，不是高铁
```

## 六、股息可持续性

| ✅ 支撑 | ⚠️ 压力 |
|---------|---------|
| 在手订单3461亿 → 1.3年收入锁定 | 国内新建里程持续萎缩 |
| 维保后市场418亿(+25%)→存量车越来越多 | 国铁债务压力→采购不确定 |

| 央企信用→现金流稳定 | 利润增速慢(6%)→分红增长空间有限 |
| 2025首推中期分红→分红意愿增强 | 派息率52%不算激进但也不会暴增 |

## 附：中车 vs 中铁 — 收息选谁？

同是央企、同是铁路产业链、同样"便宜+高股息"，但风险不是一个量级。

### 股息率的陷阱

同一家公司，A/H 股息率差异揭示了什么：

| | 中车 A | 中车 H | 中铁 A | 中铁 H |
|---|---|---|---|---|
| 股息率 | 5.71% | 5.78% | **~6%** | **~2.6%** |
| A/H差值 | ~0% | | **~3.4%** |

中车 A/H 股息率几乎一致 → 说明分红确定性强，两个市场定价趋同。中铁 A/H 差 3.4% → H 股在给更高的风险折价，说明市场对中铁分红的可持续性存疑。

### 最坏情景推演

| | 中车 | 中铁 |
|---|---|---|
| **核心风险** | 国内新建投资萎缩 → 新订单减少 | 应收账款坏账 → 直接没钱分 |
| **但** | 存量4.8万km高铁维保不会消失 | 地方债危机 → 客户付不起 |
| **最坏利润** | 腰斩（50%↓） | 可能蒸发30%+ |
| **最坏分红率** | 从52%降到30% | 从18%降到0% |
| **最坏股息率** | ~1.5% — **还有** | **归零** |
| **本质区别** | 量变：分红变少 | 质变：分红可能消失 |

### 底线

中车最坏的结果是"分红变少"，中铁最坏的结果是"分红没有了"。前者是量变，后者可能质变。所以在收息的框架下，中车比中铁靠谱得多。
