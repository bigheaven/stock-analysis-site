# 中国中铁 (601390.SH / 00390.HK) — 便宜背后的代价

> **免责声明**：本报告基于公开信息整理，不构成任何投资建议。
>
> **数据截止日期**：2026-07-18
>
> **相关信息**：[[crrc-00-overview|中国中车概览]]、[[bubble-anatomy-framework-泡沫解剖框架|泡沫解剖框架]]

## 一、一句话定位

**中国最大铁路基建承包商，营收是市值的8.5倍。但净利率仅2.4%、应收款658亿（超市值一半）、负债率78%。看起来极便宜（PE 4.6x），但便宜是市场对它的商业模式给出的合理定价。**

## 二、"诱人" vs "代价"

| | 看起来 | 实际上 |
|---|---|---|
| 营收/市值 | **8.5倍** ← 极其罕见 | 建工行业特性：收入巨大、利润极薄 |
| PE | **4.6x** ← 极低 | 利润在下滑(-18%)，还在恶化 |
| PB | **~0.24x** ← 严重破净 | 净资产里大头是应收账款 |
| 股息率 | ~3.2% | 派息率仅18%（中车52%） |
| 毛利率 | — | **9.34%**（卖100赚9块） |
| 净利率 | — | **2.42%**（卖100到手2块4） |

## 三、关键数据

```
股价：5.20元 | 市值 ~1284亿
2025营收：10,906亿(-5.8%) | 净利：228.9亿(-17.9%)
ROE：6.17% | 负债率：78.12%
应收账款：658亿（= 市值51% = 净利2.9年）
经营现金流：Q1 -77亿，Q1-Q3均为负，仅Q4回正
```

## 四、历年股息

```
每10股分红：2020:1.8 | 2021:2.0 | 2022:2.0 | 2023:2.0
2024: 2.1+0.82(中期) | 2025: 0.86+0.82(中期)=1.68
当前股息率：~3.2% | 派息率：18.1%（中车52%）
```

## 五、最大的雷：应收款

```
应收账款 658亿 = 市值51% = 净利2.9年

谁欠的：地方政府、城投平台、国铁集团
什么时候还：不知道
当前环境：地方卖地收入骤降、城投融资收紧

对比中车：
中车客户 = 国铁集团（中央政府信用）
中铁客户 = 31省+几百地级市+海外
→ 中铁应收款风险比中车大一个量级
```

## 六、中铁 vs 中车：要收股息选谁？

| | 中车 | 中铁 |
|---|---|---|
| PE | 12x | **4.6x** |
| **股息率** | **5.71%** | 3.2% |
| 派息率 | 52% | 18% |
| 毛利率 | 21.3% | 9.3% |
| 护城河 | 100%垄断 | 需竞争 |
| 应收款风险 | 低（国铁） | **高（地方债）** |
| 适合 | ✅ 收息 | ⚠️ 博反转 |

## 七、什么时候才值得看

三个信号至少看到两个：

1. **应收账款/营收比开始下降** → 回款加速
2. **经营现金流全年均匀回正** → 不再只靠年底
3. **派息率提升到30%+** → 管理层对现金流有信心

当前三个信号一个都没出现。
