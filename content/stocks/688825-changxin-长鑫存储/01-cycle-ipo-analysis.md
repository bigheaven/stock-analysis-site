## 一、存储行业当前周期位置

```
存储超级周期时间线

  2024H2         2025          2026H1        2026H2        2027-2028
  ──────        ──────        ──────        ──────        ──────────
  库存修复       价格暴涨       盈利爆发       产能扩张       新增供给释放
  AI需求启动     DRAM+340%      三巨头90%毛利  长鑫IPO       价格下行拐点？
  三星扭亏       NAND+320%      市值破万亿      Capex飙升     周期顶部确认？
  
  我们在这里 ──────────────────────→ 风险窗口在2027H2
```

**当前处于**：盈利兑现与估值重估的中后段。Q2 DRAM合约价环比+58-63%仍在涨，但边际增速可能已在放缓。

## 二、为什么存储股在"暴跌"

全球三巨头 2026年至今涨幅 120-270%，但 6-7月剧烈回调：

| 信号 | 详情 |
|------|------|
| 三星前总裁预警 | "中国企业大幅扩产，2027H2供给激增，价格或下跌" |
| SK海力士 Q2 预期miss | 营业利润比市场共识低 8% → 股价当日-15.37%（最大跌幅纪录） |
| HBM 的利润尴尬 | HBM 晶圆消耗是普通DRAM 3倍，短期每片晶圆**利润反而不如DDR5** |
| 拥挤交易获利了结 | 三巨头市值合计 3.8万亿美元，年初至今翻倍+ |
| 垄断诉讼 | 美国联邦反垄断集体诉讼，指控三巨头合谋限制DRAM供应 |

**核心矛盾**：基本面还在涨，但股价已经在提前定价"2027-2028供给过剩"。存储是**强周期品**，股价总是领先基本面6-12个月。

## 三、孙宇晨的逻辑拆解

> "短期缺芯片，长期缺能源，永远缺存储"

```
短期缺芯片 ✅   成立：HBM/先进制程确实缺
长期缺能源 ✅   成立：AI数据中心电力需求爆发
永远缺存储 ⚠️  "永远"是错的，"结构性紧缺"才是对的

存储不缺在"有没有"，缺在"谁来做"
→ 三星/海力士/美光垄断 HBM → 暴利
→ 长鑫在通用DRAM追赶到接近 → 利润率不如三巨头
→ 长江存储在NAND弯道超车 → Xtacking 4.0已超三星同级
```

**孙宇晨漏掉的关键**：暴利必然吸引暴量供给。SK海力士五年产能翻倍，三星美光同步扩产，长鑫长江也在扩。2027-2028是产能集中释放的窗口。

### 相同点（复制中石油的风险）

1. **巨型 IPO 出现在行业利润峰值**：DRAM价格历史最高位上市
2. **看似极便宜的PE是陷阱**：个位数PE = 利润峰值，不是低估信号
3. **全民狂热**：全网"国产替代""AI核心资产""日赚3亿"
4. **散户接盘风险**：首日大概率暴涨，高位开板后持续回落

### 不同点（不复制中石油的理由）

1. **科创板 vs 主板**：对上证综指权重影响远小于2007年中石油的23-25%

> ⚠️ **修正（2026.7.18）**：这个论点本身没错，但回避了真正的问题。见下方"修正判断"。

2. **A股盘子大了10倍**：2007年总市值<30万亿，现在90万亿+，吸血效应弱

> ⚠️ **修正**：盘子大了，但AI相关IPO的**累积体量**也前所未有——智谱(万亿)+沐曦(万亿)+摩尔线程(数千亿)+长鑫(2-3万亿) = 5-8万亿新增市值。这不是单一巨无霸，是一群巨无霸同时涌来。流动性被集体耗尽。
3. **不是成熟垄断**：中石油是"已经没有增长的垄断巨头"；长鑫是"0→1的国产替代"，渗透率才8%
4. **有AI真实需求**：不是2007年纯情绪炒作，HBM/DDR5需求是真实的
5. **筹码锁定更好**：战略配售50%+网下机构40%，散户流通盘仅10%

## 五、核心判断：是不是牛市终点？

> ⚠️ **2026.7.18 修正**：之前的判断低估了长鑫的体量和AI IPO的累积效应。经重新分析，修正如下。

### 3万亿意味着什么

市场舆论认为长鑫可能冲到3万亿估值。如果成真：

```
3万亿是什么概念？
= 当前中芯国际(1.3万亿) × 2.3倍
= 寒武纪峰值(1万亿) × 3倍
= 比茅台(1.4万亿) 还大两倍
= 科创板"超级巨无霸"

流通市值至少3000亿+（按10%流通盘）
对市场流动性的抽血效应是实实在在的——无论它在哪个板
```

### 更关键：它不是孤立的

```
2026年AI相关上市/上市潮合计：

智谱AI     峰值市值1万亿+港元
沐曦股份   首日+755%，市值1.3万亿
摩尔线程   上市暴涨，市值数千亿
长鑫存储   中性2万亿，乐观3万亿
──────────────────────────
合计        5-8万亿新增市值需要消化
```

这不是"科创板一个小板块的事情"——这是**AI泡沫的集中变现窗口**。每一家都在争夺同一个流动性池子。

### 修正后的判断

```
长鑫 ≠ 中石油2.0（终结整个牛市）
长鑫 = AI泡沫的"峰值信号"（大概率终结AI/半导体这轮行情）

区别：
├── 2007中石油：终结了全部牛市（整个市场都在炒资源股）
└── 2026长鑫：大概率终结AI/半导体这轮，但不一定终结全部牛市

但如果AI是这轮牛市的主线（大概率是）
→ 主线熄火 = 牛市走到尽头的概率极高
```

**之前逻辑的漏洞**：

| 我说的 | 漏掉的 |
|--------|--------|
| 科创板对上证指数权重小 | 科创板对AI板块情绪是核心定价锚 |
| | 长鑫如果跌，所有存储概念股一起跌 |
| | 科创50ETF被动配置放大波动 |
| 不像中石油绑定上证综指 | 中石油只是"一只巨无霸" |
| | 长鑫是"一群巨无霸中最肥的那个" |
| | 抽血是集体的、累积的、加速的 |

**真正风险窗口依然在2027H2-2028**（产能释放），但**情绪顶点的标志可能在2026H2已经出现**——当AI概念集体上市/估值见顶/产业资本撤退三个信号同时出现时。

## 六、核心跟踪时间线与信号

```
2026.7.16  长鑫上市首日
           → 观察：首日涨幅/换手率/收盘价 vs 发行价

2026.Q3    DRAM Q3 合约价公布
           → 【关键信号1】涨幅是否明显收窄？
           → 如果降至个位数 = 周期见顶预警

2026.Q4    三巨头 Capex 指引 + 长鑫首份上市季报
           → 【关键信号2】Capex/营收比是否 >35%？
           → 如果是 = 扩产狂热 = 经典周期顶部信号

2027.H1    云厂商资本开支（Meta/Google/Amazon）
           → 【关键信号3】AI Capex 增速是否放缓？
           → 如果巨头开始砍Capex = 需求端见顶

2027.H2    三星前总裁预警的"供给激增"时间点
           → 【核心拐点】新增产能开始集中释放
           → 存储价格下行拐点的最可能窗口

2028       如果DRAM供过于求 → 价格下行 → 长鑫利润腰斩
           → PE从个位数跳升到几十倍 = 周期底部确认
```

## 七、如果真要做，应该怎么应对

```
短线视角（几周-几个月）：
→ 首日大概率冲高，追涨风险极大
→ 参考华润新能源首日+137% → 15天后腰斩的教训

中线视角（1-2年）：
→ 真正值得关注的不是"买不买长鑫"
→ 而是"存储周期什么时候见顶"
→ 信号：DRAM合约价涨幅收窄到个位数时

长线视角（3-5年）：
→ 长鑫是国产DRAM唯一玩家，战略价值确定
→ 但周期品必须买在"亏损/微利"时，不是买在"日赚3亿"时
→ 等存储价格崩盘、长鑫利润腰斩甚至亏损时再看
```
