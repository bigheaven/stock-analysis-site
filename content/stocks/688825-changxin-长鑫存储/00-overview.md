## 一、一句话定位

**中国唯一实现 DRAM 大规模量产的 IDM 企业，全球第四大 DRAM 厂商（市占率 7.67%→~10%）。2026年7月16日科创板上市，募资295亿为科创板第二大IPO。十年亏损熬到AI存储超级周期，2026H1预告净利500-570亿。**

**关键拐点**：2025年之前累计亏损超374亿，2025年底累计未弥补亏损近410亿。IPO募资295亿中相当部分用于填补历史亏空。2026年单季利润已超过此前所有年份的累计亏损。

| | 三星 | SK海力士 | 美光 | **长鑫** |

## 五、核心竞争壁垒

| 壁垒 | 说明 |
|------|------|
| **IDM模式** | 设计+制造+封测一体化，国内唯一 |
| **客户绑定** | 阿里巴巴、字节跳动、腾讯（200亿+长期供货协议）、小米/OPPO/vivo |
| **苹果在谈** | 苹果已在测试长鑫DRAM用于中国版iPhone/iPad |
| **国产替代刚需** | 中国存储芯片自给率仅15%，国产替代空间巨大 |

## 六、核心风险

| 风险 | 详情 |
|------|------|
| **周期顶部上市** | DRAM价格处于历史高位，2026H2后可能回落 |
| **美国管制** | EUV等先进设备受限，HBM良率仅~25%，技术代差明显 |
| **盈利不可持续** | Q1净利248亿是在"DRAM涨价340%"的极端条件下，难以维持 |
| **Capex黑洞** | 每轮扩产数百亿，本次募资295亿仍不够，未来需持续融资 |
| **苹果不确定性** | 地缘政治可能导致合作审批受阻 |
