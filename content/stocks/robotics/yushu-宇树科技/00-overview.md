## 五、客户结构

```
2025前三季度收入来源：
├── 科研教育 >50%    ← 获多所知名高校采购
├── 商业消费          ← 文娱表演/展会展厅
├── 工业应用          ← 工厂巡检/搬运（拓展中）
└── 海外 ~40%        ← 较2024年国内占比反超
```

**核心争议**：科研客户>50%，复购不稳定，易受预算影响。宇树自己也承认，面向工业和家庭的大规模商业化还需突破"具身大模型"和"灵巧手精细度"。

## 六、核心竞争力

1. **唯一盈利**：行业唯一正向商业循环（营收+利润+现金流），2025扣非6亿
2. **毛利率碾压**：人形机器人62.91%（行业均值35-47%），全栈自研零部件是核心
3. **成本控制极致**：创始人王兴兴"制造业思维"贯穿公司，G1起售价压到8.5万
4. **三登春晚**：2021四足→2025《秧BOT》→2026《武BOT》，品牌壁垒
5. **技术全栈**：自研电机、减速器、激光雷达、运动控制模型

## 七、关键风险

| 风险 | 详情 |

| **科研客户依赖** | >50%收入来自高校/政府，复购不稳定 |
| **"大脑"落后** | 募资48%投向具身大模型，说明自知AI是短板 |

| **政策压力** | 工信部要求"2026年底进真实场景，禁止仅靠表演融资" |
| **估值昂贵** | 420亿发行市值 vs 2.88亿净利 = **145x PE** |
