## 一、一句话定位

**原为风电叶片材料公司，2025年被智元机器人收购控股，成为A股"具身智能壳资源"。股价从7.8元飙至187.6元(+2300%)，当前市值600亿+中绝大部分是智元期权定价。**

## 二、控制权变更时间线

| 时间 | 事件 |
|------|------|
| 2025.7.8 | 公告：智元以"协议转让+要约收购"取得63.62%股权，总价~21亿 |
| 2025.7.9 | 复牌，开启**11连板** |
| 2025.9.22 | 协议转让股份过户完成，智元正式控股 |
| 2025.11.6 | 要约收购交割完成，法律程序全部走完 |
| 2025.12.31 | 发布「上纬启元」品牌+Q1个人机器人 |
| 2026.5.25 | "稚晖君"彭志辉正式出任董事长，田华任CEO |
| 2026股价高点 | **187.6元**（较收购前7.8元涨2300%） |

## 五、核心矛盾

```
上纬新材 600亿+ 市值 = 传统材料业务 ~30-50亿 + 智元期权 ~550亿+

智元自己估值才150亿，壳却值550亿？
→ 市场在赌：智元未来会把机器人资产注入上市公司
→ 但智元明确说"36个月内不借壳"
→ 这个期权要等至少3年
```

## 六、核心风险（极高）

1. **机器人零收入**：Q1烧了3778万研发，纯支出无回报
2. **传统业务承压**：海运成本上升+原材料波动+行业竞争→毛利下滑
3. **智元不注入资产**：如果3年后真的不借壳，壳价值归零
4. **智元自身也在亏钱**：150亿估值的人形机器人公司，至今未盈利
5. **21亿收购含贷款**：智元用并购贷款收购，杠杆压力
