# 迈瑞医疗（300760.SZ）· 海外业务含金量深挖

> **免责声明**：本文为基于公开信息的综合分析，**不构成任何投资建议**。所有结论含主观判断，投资决策与风险由读者自担。
>
> **数据截止日期**：2026-07-05（当前价 ~140 元）
>
> **信息来源**：迈瑞 2024/2025 年报、2026 Q1 季报、经济参考报、新华网、证券时报、东吴证券研报、港交所 H 股招股书（更新版）等。详见文末引用源。

## 一、核心命题

> **海外业务（占比已 53%）的高增长，能否真正对冲国内下滑？其"含金量"如何？关税与地缘政治会否抵消增长？**

这是判断迈瑞未来 3 年能否企稳的关键——如果海外是"真增长、真利润"，则国内周期底一旦确认，估值有修复空间；如果海外是"低价冲量、利润稀薄"，则对冲效果有限。

## 二、区域结构拆解

### 2025 全年海外 176.50 亿（+7.40%，占比 53%，首超国内）

```
海外收入结构（2025）
┌────────────────────────────────────────────────────┐
│  欧洲          ~17% 增速     高端突破（前100医院17家）│
│  新兴市场      +近 30%       巴西/秘鲁/土耳其集采突破 │
│  独联体/中东非 双位数         本地化生产推进           │
│  北美          ~26 亿（平稳） 美敦力合作(2026-01)      │
└────────────────────────────────────────────────────┘
新兴市场贡献国际收入 65%
```

### 2026 Q1 海外加速（关键积极信号）

| 指标 | 2026 Q1 | 信号 |
|---|---|---|
| 国际收入 | +15.70%（美元口径 +20%） | ✅ 加速（vs 2025 全年 +7.40%） |
| 欧洲 | +25% | ✅ 三大产线全线发力 |
| 发展中国家 | +15%（美元 +19%） | ✅ 持续 |
| 国际 IVD | +20% | ✅ 装机兑现 |
| 国际免疫 | +30% | ✅ 高端试剂放量 |

**重要观察**：2026 Q1 海外增速（+15.70%）显著高于 2025 全年（+7.40%），说明海外不是"低基数反弹"，而是装机与客户突破后的加速兑现。这是五条线中最确定的正向力量。

## 三、海外毛利率 vs 国内：含金量研判

公开数据未单独披露海外毛利率，但可从以下线索推断：

```
海外毛利推断线索
═══════════════════════════════════════════════════════
+ 海外以设备为主（生命支持国际占比 74%、影像 65%）
  设备毛利率通常高于试剂（试剂集采压价）
+ 海外高端客户突破（前100医院17家、IDN系统）
  高端产品溢价更高
+ 本地化生产（14 国基地、11 个投产）
  规避关税 + 降低物流成本
- 发展中国家货币贬值（高息滞胀）
  汇兑损失 + 采购力下降
- 美团 25% 关税（北美 ~26 亿受影响）
═══════════════════════════════════════════════════════
综合推断：海外毛利率可能 ≥ 国内（设备占比高 + 高端溢价）
       但被汇率与关税部分抵消
```

**对冲测算**：2025 国内 -22.97%（156.32 亿）、海外 +7.40%（176.50 亿）。假设国内毛利 55%、海外毛利 62%，则 2026 若国内再 -10%、海外 +15%，整体毛利可基本持平——**海外是整体毛利率的稳定器**。

## 四、关税与地缘敏感性测算

### 美国 25% 关税情景

```
基准：北美收入 ~26 亿（2024），占整体 ~7%
当前关税：部分品类 25%

情景A（维持现状）：北美平稳，影响有限
情景B（扩展至全品类 25%）：北美收入承压
  → 若北美 -15%，影响整体收入 ~1.1%（26×15%/332）
  → 但迈瑞可通过本地化生产(14国基地)转移产能
情景C（极端升级）：北美退出风险
  → 影响 < 8% 收入，可控
```

**结论**：美国关税是"噪音级"风险而非"致命级"——北美占比仅 ~7%，且迈瑞有 14 国本地化产能可转移。真正的地缘风险在于**发展中国家货币贬值**（高息滞胀致采购力下降），这部分占国际收入 65%，但 2026 Q1 数据显示新兴市场仍 +15%，说明影响可控。

## 五、海外对冲国内的可持续性判定

**结论：可持续，且是迈瑞未来 3 年最确定的增长引擎。**

| 维度 | 判断 | 依据 |
|---|---|---|
| 市场空间 | ✅ 充足 | 海外可及市场是国内 4—5 倍 |
| 市占率 | ✅ 低基数 | 海外平均市占率远低于国内（生命支持海外占比 74% 但绝对份额低） |
| 客户突破 | ✅ 高端化 | 全球前 100 医院 17 家、IDN 系统、美敦力合作 |
| 产能本地化 | ✅ 14 国基地 | 11 个投产，规避关税 |
| 增速验证 | ✅ Q1 加速 | +15.70% 高于 2025 全年 +7.40% |

**目标**：公司提"十年进入全球前十"。2024 全球排名第 23。海外占比从 53% 继续升至 60%+ 是大概率事件。
