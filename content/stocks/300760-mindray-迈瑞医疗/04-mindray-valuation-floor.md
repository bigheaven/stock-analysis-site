# 迈瑞医疗（300760.SZ）· 估值底研判

> **免责声明**：本文为基于公开信息的综合分析，**不构成任何投资建议**。所有结论含主观判断，投资决策与风险由读者自担。
>
> **数据截止日期**：2026-07-05（当前价 ~140 元，PE ~21.7x）
>
> **信息来源**：东方财富/中财网行情、东吴证券/浙商证券研报、迈瑞 2024/2025 年报、2026 Q1 季报等。详见文末引用源。

## 一、核心命题

> **增速转负背景下，20x PE 能否守住？迈瑞是"已低估"还是"估值还有下修空间"？**

这是决定"会不会亏太多"的核心。估值底若守住，下行空间有限；若估值中枢继续下移至 15x，则当前价仍有 25% 下行空间。

## 四、20x PE 能否守住——核心判定

```
支持 20x 守住（已低估）：
  • 前瞻 PE 19x < 静态 21.7x，预期已下修
  • 海外 +15.70% 成长性不应纯按价值股定价
  • 行业折价 -61% 过深
  • 65.27% 分红率 + 累计 377 亿分红支撑
  • 卖方一致目标价仍高于现价

支持下修至 15x（还有空间）：
  • 2025 净利 -30.28%，增速转负年份估值中枢通常下移
  • 114.65 亿商誉减值风险未释放
  • 国内周期底未确认，2026 可能仍负
  • H 股稀释预期
  • 价值股在增速转负时 PE 常跌至 12—15x
```

**判定：20x PE 大概率能守住，但 15x 是悲观情景下限。** 理由：海外成长性（+15.70%）+ IVD 转正（+4.96%）+ 先行指标转正，三者构成估值底支撑；但若 2026 半报国内仍深负 + 商誉减值，15x 情景不能完全排除。

## 五、三档情景估值带

```
┌─────────────────────────────────────────────────────────────────────┐
│  情景    │ PE   │ 2026E EPS │ 目标价 │ 概率  │ 触发条件            │
├─────────────────────────────────────────────────────────────────────┤
│  悲观    │ 15x  │  7.00*    │ ~105  │ 25%   │ 国内继续深负+商誉减值│
│  中性    │ 20x  │  7.27     │ ~145  │ 50%   │ 2026国内收窄、2027转正│
│  乐观    │ 25x  │  7.50**   │ ~188  │ 25%   │ 国内V型+海外+15%+重估│
└─────────────────────────────────────────────────────────────────────┘
* 悲观情景假设 2026 净利低于东吴预测（如商誉减值致 EPS 下修至 7.0）
** 乐观情景假设国内超预期恢复、EPS 略高于预测
加权期望目标价 = 105×0.25 + 145×0.50 + 188×0.25 = ~146 元
```

**对比当前 140 元**：加权期望 146 元，上行空间约 +4%；悲观下限 105 元，下行空间约 -25%。

## 六、估值失效边界

```
1. EPS 基数失真
   2025 EPS 6.71（-30.28%）为异常低基数
   → 应以 2024 EPS 9.62 为正常化基数交叉验证
   正常化 PE = 140 / 9.62 = 14.6x（更具安全边际）

2. 商誉减值风险
   商誉 114.65 亿（2025 Q3，5 年 +836%）
   主因 Hytest/DiaSys/惠泰收购
   → 惠泰 2024 高溢价收购，若 2026 减值将扭曲净资产与 EPS
   → PB 估值参照系可能突变

3. ROE 下台阶
   ROE 32.58% → 21.58%（-11pct）
   → PB 估值中枢应下移，3.79x 不一定便宜

应对：以正常化 EPS + FCF 估值为主，PB 为辅
   2025 经营现金流 101.45 亿，FCF 估值约 1400-1600 亿市值，与当前市值吻合
```

## 七、估值底判定

**结论：估值底约在 105—115 元（悲观情景 15x × 下修 EPS），当前 140 元距估值底约 -20%—25% 下行空间；但加权期望 146 元表明当前价已接近合理估值中枢。**

- **短期（6 个月）**：估值底受业绩与资金面主导，若 2026 半报国内仍深负，可能下探 115—125
- **中期（1—3 年）**：若 2027 国内转正 + 海外持续，估值有望修复至 20—25x，对应 145—188
- **关键变量**：商誉减值是否触发、国内拐点确认时点、H 股稀释程度
