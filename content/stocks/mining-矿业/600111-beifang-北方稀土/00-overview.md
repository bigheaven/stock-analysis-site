## 一、一句话定位

**全球最大稀土企业，白云鄂博矿独家开采权（占全国90%、全球50%）。国家配额占比70%，政策+资源双重护城河。但冶炼加工毛利率仅13%，是矿企中最低的"伪龙头"。PE 49x四家中最贵，股息率仅0.35%。适合趋势投资，不是收息标的。**

## 二、关键数据

```
市值：1,354亿 | PE 49.4x | PB 5.39x | 股息率 0.35%

氧化镨钕价格：
2024低位 34.5万/吨 → 2025均价 50.13万 → 当前 76.73万/吨(+122%)

业绩：
2024净利 10.04亿（腰斩）→ 2025 22.51亿(+124%) → 2026H1E 19.8-20.6亿
→ H1已接近2025全年，全年有望冲击 40-50亿

毛利率 13.22% | 净利率 8.83% | ROE 3.65%(Q1)
资产负债率 36.83% | 经营现金流 Q1 -2.72亿
```

## 三、"伪龙头"的真相

```
北方稀土 = 垄断资源 + 加工利润

资源端：白云鄂博 → 世界级矿 → 国家级垄断 → ✅ 真龙头
加工端：冶炼分离 → 毛利率仅8-13% → ❌ 赚的是辛苦钱

对比：
天齐锂业 毛利率 63% → 矿端直接赚暴利
紫金矿业 毛利率 36% → 矿山开采利润厚
赣锋锂业 毛利率 30% → 加工+上游混合
北方稀土 毛利率 13% → 守着全球最大稀土矿，但加工环节留不住利润
```

**为什么垄断了还赚不到钱？** 因为稀土的瓶颈不在资源稀缺性，而在冶炼分离是低附加值环节。就好比你垄断了全国的面粉供应，但干的活是磨面粉——利润远不如卖面包的人。北方稀土的战略应对是向下游延伸做磁材（"从面粉到面包"），但目前磁材收入占比还小。

## 四、周期属性

```
稀土价格周期（氧化镨钕）：

2023H2：88.8万 → 开始下跌
2024H1：最低 34.5万（-61%）
2024Q4：《稀土管理条例》施行 → 触底反转
2025：均价 50.13万（+24.5%）
2026：加速上行至 76.73万（+122% vs 低谷）

周期驱动力：
├── 供给端：国家配额制度（指标增速从20%+→5.88%）→ 供给刚性
├── 需求端：新能源车+风电+人形机器人+低空经济
└── 政策端：《稀土管理条例》规范行业，边际利好龙头

北方稀土 = 最纯的稀土价格β：
稀土价格涨50% → 利润翻倍+
稀土价格跌50% → 利润腰斩（2024已经验证）
```
