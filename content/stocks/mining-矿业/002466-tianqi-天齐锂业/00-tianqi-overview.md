# 天齐锂业 (002466.SZ / 9696.HK) 概览

> **数据截止日期**：2026-07-18
>

## 一、一句话定位

**全球成本最低的锂辉石矿（Greenbushes）的控股方 + 智利最优盐湖（Atacama/SQM）的参股方，A股锂价弹性最大的标的。**

## 二、业务结构

```
纯上游资源型：
├── 锂精矿开采与销售（Greenbushes 51% + 外售）
├── 锂化工产品（碳酸锂/氢氧化锂，自有加工产能约12.16万吨/年）
└── 对联营公司 SQM 的投资收益（持股21.9%）

锂矿自给率：接近 100%
```

## 三、核心资产地图

### 皇冠上的明珠：Greenbushes 锂辉石矿

| 指标 | 数据 |
|------|------|
| 位置 | 西澳大利亚 |
| 品位 | 2.8%（全球最高） |
| 资源量 | 16,510万吨原矿 = 833万吨LCE |
| 储量 | 8,640万吨原矿 = 500万吨LCE |
| 产能 | 162万吨精矿/年 + CGP3 新投产 52万吨 |
| 现金成本 | 约5-6万/吨 LCE（全球成本曲线最左端）|
| 未来 | 规划 CGP4（52万吨），预计2027年投产 |

### 盐湖王牌：Atacama (SQM)

| 指标 | 数据 |

| 持股 | 天齐持有SQM约21.9%股权 |
| 成本 | 约5-7万元/吨（最低成本梯队） |
| 2026影响 | SQM Q2业绩预计同比大幅增长 → 投资收益暴增 |

## 四、与赣锋的关键差异

| 维度 | 天齐 | 赣锋 |
|------|------|------|
| 模式 | 纯上游资源型 | 全产业链 |
| 毛利率 | 70%+ | 40-50% |
| 锂价弹性 | **最大**（矿端利润直接放大）| 大但受限 |
| 抗风险 | 较弱（满仓资源）| 较强（电池对冲）|
| 概念溢价 | 无（纯资源）| 固态电池 + 储能 |
| 核心风险 | 海外地缘政治 | 外购矿成本控制 |
| 资产负债率 | ~28%（已修复）| — |

## 六、核心跟踪变量

### 短期（月度）
- [ ] Greenbushes CGP3 达产进度 → 2026年最大自有增量
- [ ] SQM Q2 实际业绩 vs 彭博预测
- [ ] 锂精矿外售价格与量（加工价差）
- [ ] 碳酸锂现货价格（天齐利润对此极度敏感）

### 中期（季度）
- [ ] Greenbushes CGP4 建设进度（2027年投产）
- [ ] 四川雅江措拉锂矿开发进度（与紫金合作）
- [ ] 智利 SQM 国有化谈判进展（政治风险）
- [ ] 机构评级变化（瑞银目标价93元 vs 大和"沽售"）

### 长期（年度）
- [ ] 澳洲 FIRB 对外资矿权态度变化
- [ ] Greenbushes 从露天转地下开采 → 远期成本上升
- [ ] 锂资源全球竞争格局（天齐"走出去"的空间还有多大）

## 七、周期波动与安全边际

```
天齐锂业的"极致周期股"属性：

上涨期弹性：
锂价 10→20万/吨 → 矿端利润可能翻3-5倍（SQM投资收益同步暴增）
→ 这是2026H1 净利润暴增32-49倍的本质

下跌期风险：
锂价 20→6万/吨 → 2024年巨额亏损的先例仍在
→ 矿端固定成本高，利润碾压式下滑

安全边际的唯一来源：
Greenbushes现金成本5-6万/吨 → 锂价跌到全球90%产能亏损时
天齐仍能盈利 → 行业最差时能活下去 = 周期底部的终极保护

当前位置 (2026.7)：
→ 业绩峰值附近 → 市场正在定价"见顶"逻辑
→ 股价回撤43%已反映部分悲观预期
→ 但若高盛预测成真（锂价跌至6.5万）→ 仍有较大下行空间
→ 若瑞银预测成真（锂价20万+） → 当前股价被显著低估
→ 分歧极大 = 波动极大

跟踪核心：不是"天齐值多少钱"，而是"锂价会去哪"
→ 参考 [[lithium-cycle-tracker-锂业周期跟踪]] 三层指标体系
```
