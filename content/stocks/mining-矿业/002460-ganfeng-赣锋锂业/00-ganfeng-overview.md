# 赣锋锂业 (002460.SZ / 1772.HK) 概览

> **免责声明**：本文仅为公开信息整理与框架分析，**不构成任何投资建议**。
>
> **数据截止日期**：2026-07-18
>
> **跟踪框架**：[[lithium-cycle-tracker-锂业周期跟踪]] — 锂行业周期跟踪

## 一、一句话定位

**全球最大锂盐加工商 + 全产业链一体化布局（资源 → 锂盐 → 电池），固态电池概念加持。**

## 二、业务结构

```
2025年营收构成：
├── 锂系列产品 55.8%  ← 核心利润来源（碳酸锂/氢氧化锂/金属锂）
├── 锂电池系列 35.7%  ← 差异化布局（储能+固态电池）
└── 其他 8.5%

毛利率：~40-50%（低于天齐，因外购矿成本）
锂矿自给率：~50%（提升中，目标更高）
```

## 三、核心资产地图

### 上游资源（全球权益储量 3072万吨 LCE，世界第一）

| 项目 | 位置 | 类型 | 状态 |
|------|------|------|------|
| Mount Marion | 澳洲 | 锂辉石 | 在产，43%权益 |
| Goulamina | 马里 | 锂辉石 | 一期50.6万吨精矿已投产，爬坡中 |
| Mariana | 阿根廷 | 盐湖 | 一期已投产，爬坡中 |
| Cauchari-Olaroz | 阿根廷 | 盐湖 | 在产 |
| 青海盐湖 | 中国 | 盐湖 | 金属锂项目试生产 |
| 江西锂云母 | 中国 | 锂云母 | 在产 |

### 中游加工（全球最大锂盐加工产能）

- 五大类逾 40 种锂化合物及金属锂产品
- 产能覆盖碳酸锂、氢氧化锂、金属锂、丁基锂等全谱系
- 电池级硫化锂产线释放产能（固态电解质关键材料）

### 下游电池（差异化杀手锏）

- 赣锋锂电：储能电池 + 固态电池
- 固态电池：400Wh/kg 循环寿命突破 1100 次，500Wh/kg 产品小批量量产
- 2026年6月完成 20亿元增资扩股（工银金投等银行系战投）
- 2025年锂电池收入 82.33亿元（+39.63%）

## 四、与天齐的关键差异

| 维度 | 赣锋 | 天齐 |
|------|------|------|
| 模式 | 全产业链 | 上游资源型 |
| 毛利率 | 40-50% | 70%+ |
| 锂价弹性 | 大（但需扣外购矿成本）| 更大（矿端利润直接放大）|
| 抗风险 | 较强（电池业务对冲）| 较弱（纯资源周期）|
| 概念溢价 | 固态电池 + 储能 | 纯资源 |
| 核心风险 | 外购矿成本侵蚀利润 | 海外地缘政治 |

## 六、核心跟踪变量

### 短期（月度）
- [ ] 锂盐销量 vs 产量（产能利用率）
- [ ] 外购矿比例变化（自给率提升 = 利润率提升）
- [ ] 固态电池客户认证进度、出货量
- [ ] 赣锋锂电储能订单

### 中期（季度）
- [ ] Goulamina 产能爬坡进度（2026年最重要增量）
- [ ] Mariana 盐湖爬坡
- [ ] 锂盐加工价差（碳酸锂 - 锂精矿）
- [ ] 机构评级方向（高盛已下调至"卖出"，关注其他机构跟进情况）

### 长期（年度）
- [ ] 固态电池商业化进展（若突破，对估值体系是颠覆性的）
- [ ] 锂资源自给率目标达成
- [ ] 锂电池板块能否持续贡献第二增长曲线

## 七、周期波动与安全边际

```
赣锋"一体两翼"的周期含义：

锂价上涨期 → 资源端+加工端双重受益，但弹性不如天齐
锂价下跌期 → 电池业务缓冲业绩，跌幅可能小于纯资源股
              但外购矿部分可能因价格倒挂而亏损

当前阶段 (2026.7)：
→ 业绩暴增（H1预告）+ 股价暴跌（-40%）= 典型的周期股"买预期卖事实"
→ 市场交易的是"2027供给过剩"预期，不是当下业绩
→ 固态电池概念为估值提供了一定支撑（对比天齐PE更高）
```
