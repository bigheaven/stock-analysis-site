## 一、一句话定位

**中国最大钴冶炼商 + 印尼镍湿法冶炼第一梯队。核心故事是从"买矿"到"去印尼建厂"的一体化转型。但硫磺断供事件暴露了供应链的系统性脆弱——全球化的好处它吃到了，去全球化的代价它也逃不掉。**

## 二、20→82→37 的逻辑链

```
2025年最低 20元 → 2026年最高 82元 → 当前 37元

三重上涨驱动力（20→82，+310%）：
├── 🏆 钴价暴升 +140%（刚果出口配额 → 全球钴供给锐减一半）
│   → 华友印尼湿法MHP副产钴 → 完美对冲刚果减产
├── 🥈 镍价反弹 +30%（印尼RKAB配额收紧 + HPM新政托底）
├── 🥉 业绩爆发：2025归母61亿(+47%)，2026Q1 25亿(+99%)

四重暴跌压力（82→37，-55%）：
├── 💣 硫磺断供（直接导火索）
│   → 2月中东冲突 → 印尼75%硫磺来自中东 → 现货破800美元/吨
│   → 华飞12万吨湿法项目5月起停产50%
│   → 华飞占营收17.89%
├── 💸 经营现金流暴降68%（124亿→40亿）
│   → 高杠杆扩张模式的脆弱性暴露
├── 🐻 镍价从19,635回落至17,045
│   → 存货减值担忧
├── 🔪 宁德时代成立300亿"时代资源集团"
│   → 从最大客户变成直接竞争对手
```

## 三、华友 vs 赣锋/天齐：周期野兽对比

| | 华友钴业 | 赣锋锂业 | 天齐锂业 |
|---|---|---|---|
| **核心金属** | 镍+钴+铜 | 锂(加工为主) | 锂(矿端为主) |
| **资源来源** | 印尼建厂(湿法) | 全球多矿源 | Greenbushes+SQM |
| **2025净利** | 61亿(+47%) | — | 30→28亿(Q1) |
| **当前PE** | **9.5x** | ~14-16x | ~10-11x |
| **核心风险** | **地缘供应链断裂！** | 锂价周期 | 海外资产政治风险 |
| **商业模式** | "借印尼的矿，赚中国的钱" | 加工+上游布局 | 纯矿端 |
| **2026暴雷** | 硫磺断供→工厂停产 | — | — |

**华友是三个里最"野"的——它比锂业多了两个变量：地缘政治（中东→硫磺→印尼工厂）、客户竞争（宁德从伙伴变对手）。**

```
└── 宁德时代自建资源后订单流失？
```

## 五、三次危机全历史

华友钴业上市以来经历了三次大的危机，每次根源完全不同：

| 时间 | 危机 | 股价表现 | 根源 | 性质 |
|------|------|----------|------|------|
| **2022.3** | 青山镍逼空 | 连续两日跌停，市值蒸发261亿 | LME镍两天从2.8万→10万美元，嘉能可逼仓青山 | 金融狙击 |
| **2024** | 周期底部 | 跌至20元 | 钴镍价格崩盘+印尼产能过剩+去库存+高杠杆 | 供需过剩 |
| **2026.2** | 硫磺断供 | 82→37（-55%） | 中东冲突切断印尼硫磺供应→华飞停产50% | 地缘断裂 |

### 2022年：青山镍逼空

```
背景：青山集团在LME持有10-20万吨镍空头头寸（套保）
     → 嘉能可逼仓，镍价两天涨250%
     → 青山在印尼的镍矿成本仅8000美元/吨，但LME交割需要纯镍
     → 青山产的是镍铁/高冰镍，纯度不够，交不出货

华友遭受冲击：
     → 与青山在印尼有合作项目（华越湿法冶炼）
     → 市场担心：如果青山被逼仓破产，其印尼镍矿60%权益会被嘉能可拿走
     → 华友连续两日跌停，市值蒸发261亿
     → 最终LME取消交易、延迟交割 → 青山获救 → 华友股价修复
```

### 2024年：产能过剩+周期底部

```
五重压力叠加：

1. 钴价崩盘
   钴：57万/吨(2022峰值) → 25万(2023) → 跌穿历史周期底部(2024)
   印尼湿法MHP大量释放 → 镍钴中间品从稀缺变过剩

2. 镍产能过剩
   印尼占全球60%+，华友/青山/格林美同时扩产
   LME库存25万吨+ 历史高位

3. 电池需求放缓+去库存
   新能源车增速放缓 + LFP挤压三元份额 + 行业去库存

4. 财务杠杆承压
   印尼项目单个湿法投资数十亿美元
   金属价格暴跌 × 高杠杆 = 戴维斯双杀

5. 青山镍逼空余震
   虽已过去，但暴露了供应链脆弱性

→ 20元 = 市场在定价"高杠杆模式可能撑不过周期底部"
```

### 2026年：地缘断裂（当前）

```
见上文「20→82→37」分析。

→ 82→37 = 硫磺断供（华飞停产50%）+ 宁德自建资源（客户变对手）
```

### 北向砍仓 + 大股东质押：资金面双重暴击

```
北向资金：持股从7.7%→4.7%，一个季度砍仓39%，实持市值从85亿→42亿
主力资金：20日净流出24亿
→ 散户在接盘，北向在撤退

大股东质押：华友控股+陈雪华合计质押44.8%持股
→ 股价腰斩 → 可能触发补充质押 → 甚至强平风险
→ 这不是基本面问题，是筹码结构问题

但是：近三年累计分红/年均净利 = 76%，每年10派5块 — 分红意愿还行
```

### 后续新增数据（来自产业调研）

```
印尼2026年镍矿配额砍了3成 → 镍价反而有支撑
硫磺占镍成本35% → 成本曲线整体抬升 → 低成本产能（华友）优势扩大
合同负债从13亿→34亿 → 下游订单接到手软，这是最硬的先行指标

全球镍过剩从42万吨收窄到5万吨 → 几乎供需平衡
```

**三种危机，三个根源——周期股从来不是只亏一次钱，它会在不同阶段、以不同方式、给你不同的理由亏钱。**

## 六、现在37元，会不会再跌到20以下？

### 两次下跌对比

| | 2021.12→2024底部20元 | 2026.2→当前37元 |
|---|---|---|
| **跌幅** | 151→20（-87%） | 82→37（-55%） |
| **利润** | 从暴赚到亏损边缘 | 2025净利61亿，还在赚钱 |
| **钴价** | 57万→不到10美元/磅 | 刚果禁令托底 |
| **现金流** | 极度紧张 | 虽从124→40亿，仍是正的 |
| **最大风险** | 价格持续再跌三年 | 硫磺断供+宁德竞争 |
| **市场定价** | "这家公司会死在周期底部" | "利润可能恢复到正常水平" |

两次下跌环境相似（利润峰值→预期反转→戴维斯双杀），但**这次底线更高**——2024年20元是生存问题，现在37元只是估值问题。

### 跌到20以下的三个路径

有可能，但需要更极端的情景，且和2024年的触发条件完全不同：

```
路径1：钴价崩盘
刚果取消出口禁令 → 2.5亿磅库存瞬间释放 → 钴价跌回10美元
→ 华友钴业务利润归零

路径2：硫磺长期断供
中东战争持续 → 硫磺800美元+维持一年以上
→ 华飞永久停产 → 减值损失+营收缺口 → 利润腰斩

路径3：宁德时代全面翻脸
时代资源集团300亿落地 → 不再采购华友前驱体
→ 最大下游订单消失 → 产能利用率暴跌

三个路径同时发生 → 20元甚至更低
任一单独发生 → 大概率跌不到20
```

### 底线

2024年跌到20时，华友是接近亏损的。现在37元，华友还在赚60亿+。前者是生死问题，后者是估值问题。要再跌到20，需要"钴崩+硫磺断+宁德翻脸"三雷齐爆——不是不可能，但概率远低于2024年那次。
