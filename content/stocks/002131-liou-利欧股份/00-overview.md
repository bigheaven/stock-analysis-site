# 利欧股份 (002131.SZ) — 概念收割机，水泵才是本业

> **免责声明**：本报告基于公开信息整理，不构成任何投资建议。
>
> **数据截止日期**：2026-07-19
>
> **信息来源**：Wind Alice（分部财务/质押/扣非）、IMA 最全研报库

---

## 一、一句话结论

**这是一家卖水泵的公司。其余全是概念。**

半年30个涨停的逻辑不在业绩——在于它身上贴的标签足够多：商业航天、液冷、半导体、AI。每个概念爆发时它都被拉出来炒一遍，但三个概念合计营收几乎为零。

## 二、业务真相：76%的收入只贡献了33%的利润

```
2025年营收 200亿，利润拆解：

              收入占比    毛利率      利润贡献
媒介代理       76.23%     3.86%      33%  ← 流水大，利润极薄
水泵           20.72%     25.35%     60%  ← 真正的利润支柱！
数字营销服务    1.86%     33.23%      7%

媒介代理：帮广告主在抖音/快手/腾讯买流量 → 赚3.86%的手续费
→ 这就是为什么营收200亿、但扣非净利润只有3954万（净利率0.2%！）
```

## 三、概念与现实

| 概念 | 市场炒作 | 实际营收 | 判断 |
|------|----------|----------|------|
| **液冷** | AI液冷龙头 | **<0.1%营收**（<2000万） | 🟡 有送样和、小批量，最"实"的一个 |
| **商业航天** | 航天概念股 | **零** | ❌ 公司年报查无此项业务 |
| **半导体** | 芯片概念 | **零** | ❌ 有标签无业务 |
| **AI/AIGC** | AI营销平台 | 数字营销的"工具" | 🟡 降本增效，但改变不了3.86%的媒介代理毛利率 |
| **水泵** | 没人炒作 | **41亿营收，真正的利润来源** | ✅ 销往160国，毛利率25% |

## 四、扣非利润：惨不忍睹

```
归母净利润 vs 扣非净利润（近三年）：

2023：归母 19.66亿 — 但扣非只有 0.55亿
      → 19亿来自理想汽车股票公允价值变动（不是主业赚的！）

2024：归母 -2.59亿 — 但扣非反而 +1.61亿
      → 亏是因为理想股价跌了，主业在改善

2025：归母 0.34亿 — 扣非回落 0.40亿
      → 水泵受地缘冲突+原材料+汇率冲击

一句话：主业三年扣非合计 2.57亿，平均每年不到 9000万。
一家200亿营收的"AI概念股"，主业每年只赚几千万。
```

## 五、风险清单

```
1. 实质营收 = 零
   液冷<0.1%、商业航天=0、半导体=0
   这些概念在公司账上既没有收入也没有利润

2. 应收账款 58.24亿
   占总资产27%、占营收29% — 媒介代理业务的天然副产品
   但偏高，坏账风险不可忽视

3. 大股东质押 46%
   实控人王相荣 47.6% + 王壮利 43.7%
   股价从高点跌到3.84 = 质押压力在加大

4. 研报推波助澜
   IMA 搜到的研报标题："AIGC赋能增长""AI助力升级""估值双升"
   但没有一份研报敢说"液冷不赚钱、航天没业务"
```

## 六、为什么半年30个涨停？

```
每个概念来时，利欧都被拉出来"收割"一波：

2025Q4 商业航天行情 → 利欧涨停（"航天概念"）
2025Q4 科技/AI行情 → 利欧涨停（"AI营销"）
2026Q1 半导体行情 → 利欧涨停（"芯片概念"）
2026Q1 液冷行情 → 利欧涨停（"液冷概念"）

→ 市值小、筹码分散、概念多 = 游资的完美"概念收割机"
→ 每次涨停背后的逻辑是不同的概念，但水泵还是那个水泵
```

### 深交所公开谴责：业绩预告"大变脸"

```
2026.1 预告：2025年赚 1.9亿-2.5亿
2026.4 修正：缩水到 3000万-4500万（砍了80%）
实际年报：3374万

深交所处罚：董事长+财务总监 公开谴责，计入诚信档案
→ 对价值投资者 = 红线
→ 对游资短线客 = 无所谓
→ 但意味着下次利好时，"兑现即变脸"的尾行风险极大
```

### 利润靠一只股票：理想汽车

```
利欧的主业不赚钱——赚钱靠的是理想汽车(HK)的股票：

2020年：靠理想一把赚45亿 → 47.7亿净利几乎全靠它
2023年：公允价值变动+12.5亿 → 归母19.66亿（扣非仅0.55亿）
2024年：理想跌了 → 投资亏8.73亿 → 全年立刻转亏2.59亿
2025H1：还捏着约28亿理想股票没卖

→ 利欧赚不赚钱，看理想汽车股价脸色
→ 单只股票定全年盈亏，一家200亿营收的"AIGC龙头"命门是一辆电动车
```

## 七、底线

3.84元不是底，按主业算合理中枢~2.9元。2026Q1扣非已亏损3631万，深交所公开谴责是治理红线。唯一的变数是泵业分拆赴港上市（进度未定）。要参与只能当题材博弈，跌破4.25元大阳底就走——绝不当投资买。

## 八、如何发现这类"假概念"：三步筛查法

详见 [[fake-concept-detector-假概念识别]]

```
1. 查分部报告 → 概念有独立营收才可能是真的
2. 看扣非vs归母 → 差距越大、利润越"假"
3. 算应收/营收 → >25%说明钱还在账上没收回来
```

利欧在这三个关卡上全部翻车：商业航天查无此业务、扣非三年合计仅2.57亿、应收/营收=29%。
