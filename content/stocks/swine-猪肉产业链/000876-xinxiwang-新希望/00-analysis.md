# 新希望（000876）深度分析报告

> 更新日期：2026年7月21日

---

## 1. 公司概览

### 1.1 公司定位

新希望是中国最大的农牧企业之一，以**饲料+养殖双主业**为核心驱动。公司业务横跨饲料生产、畜禽养殖、屠宰加工及肉制品销售，形成从田间到餐桌的全产业链布局。

### 1.2 业务结构

| 业务板块 | 营收占比 | 主营内容 |
|---------|---------|---------|
| **饲料业务** | 71% | 猪料、禽料、水产料等全品类饲料生产与销售 |
| **养殖业务** | 27% | 生猪养殖、白羽肉禽养殖 |
| 其他（食品等） | 2% | 屠宰加工、肉制品、宠物食品等 |

### 1.3 饲料业务详解

新希望是中国最大的饲料生产企业之一，2025年饲料销量达到2,974万吨，同比增长15%。产品线覆盖猪料、禽料、水产料、反刍料等全品类，客户网络遍布全国。饲料业务的核心竞争力在于：

- **规模效应**：近3,000万吨级的产销量形成显著的采购成本优势与生产端规模效应
- **配方技术**：持续优化饲料配方，在原料价格波动中保持成本竞争力
- **客户粘性**：深耕农村市场，下沉渠道广，终端养殖户复购率高
- **盈利稳定性**：2025年饲料业务盈利11.7亿元（+20%），2026Q1盈利3亿元（+30%），呈现加速增长态势

### 1.4 养殖业务详解

养殖业务以生猪养殖为主，是公司最大的业绩波动来源：

- **养殖模式**：以"公司+农户"和自养模式相结合
- **产能布局**：主要分布在四川、山东、河北、辽宁等核心生猪产区
- **2025年出栏量**：生猪出栏约1,900万头（估算）
- **PSY**：26头（处于行业中上水平）

| 生猪业务亏损 | 23.3亿 | — | 亏损扩大 |

### 2.2 饲料业务分拆

2025年饲料业务表现强劲，量利齐升：

- **销量增长驱动**：2,974万吨销量同比+15%，主要受益于下游养殖存栏回升及市场份额提升
- **盈利改善**：盈利11.7亿元同比+20%，利润率提升至约1.1%（按营收口径），吨均利润约39元/吨
- **增长逻辑**：饲料业务作为现金牛业务，持续为公司提供稳定的现金流支撑，对冲养殖业务的周期波动

### 2.3 养殖业务分拆

2025年生猪养殖业务亏损23.3亿元，是公司整体亏损的核心原因：

- **猪价低迷**：2025年全年生猪均价维持在较低水平，行业性亏损贯穿全年
- **完全成本**：12.84元/kg，虽高于猪价但仍处于行业中位水平
- **出栏规模**：规模扩张带来的折旧摊销及固定成本分摊压力较大
- **非经常性损失**：可能包含生物资产减值及存货跌价损失

## 4. 核心竞争优势

### 4.1 饲料规模效应（核心护城河）

新希望是中国最大的饲料企业之一，近3,000万吨级的年销量构筑了强大的规模壁垒：

- **采购议价权**：玉米、豆粕等大宗原料年采购量巨大，对上游供应商具备强议价能力
- **生产端优势**：全国布局的饲料工厂网络，物流半径短，运输成本低
- **品牌与渠道**：深耕农村市场逾30年，经销商网络稳定，品牌认知度高
- **现金流贡献**：饲料业务对资金占用低、周转快，持续为公司提供稳定现金流

### 4.2 成本优化趋势

养殖成本持续下行是公司未来盈利反转的核心逻辑：

| 时间节点 | 完全成本（元/kg） | 累计降幅 |
|---------|-----------------|---------|
| 2025年全年 | 12.84 | 基准 |
| 2026Q1 | 12.22 | -0.62 |
| 2026年目标 | 11.22 | -1.62 |

按照2026年出栏约2,000万头、均重120kg测算，成本每降低1元/kg对应约**24亿元**的利润弹性。

### 4.3 全产业链优势

- **饲料-养殖联动**：内部饲料供应降低养殖成本，养殖端又为饲料提供稳定需求
- **养殖-食品延伸**：向下游屠宰加工延伸，获取产业链后端附加值
- **风险对冲**：饲料稳利润、养殖博弹性，双主业结构天然对冲周期风险

## 8. 主要风险

### 8.1 可交换债换股风险（重点关注）

| 债券信息 | 内容 |
|---------|------|
| 债券简称 | 26希望KEB1 |
| 发行规模 | 35亿元 |
| 初始换股价 | 12.38元 |
| 当前股价 | 7.08元 |
| 换股溢价率 | 约75%（远高于现价，换股价值极低） |
| 控股股东补充质押 | 1.165亿股 |

**风险分析**：

- **换股压力**：12.38元的换股价远高于当前7.08元的股价，短期内换股行权概率极低
- **质押风险**：控股股东已补充质押1.165亿股，若股价持续下跌可能面临追加质押或平仓风险
- **间接影响**：可交换债的存在加大了控股股东的财务压力，可能影响其对公司经营的支持力度
- **到期兑付**：若到期时股价仍低于换股价，控股股东需以现金兑付，将加大其资金压力

### 8.2 猪价持续低迷风险

- 若猪价反转时间推迟至2027年，公司2026年全年亏损可能扩大至30亿+
- 持续亏损将侵蚀净资产，降低PB支撑位
- 可能导致生物资产减值、存货跌价损失等非经常性损失

### 8.3 养殖成本下降不及预期

- 2026年降本1元/kg目标依赖饲料成本、生产效率、管理改善等多重因素
- 任何环节的拖累都可能影响成本下降节奏
- 成本下降不及预期将压缩猪价反弹后的盈利弹性

### 8.4 饲料业务增速放缓风险

- 饲料行业竞争加剧，中小企业出清速度可能放缓
- 原料价格波动影响毛利率
- 养殖端存栏波动影响饲料需求

### 8.5 财务风险

| 风险指标 | 关注点 |
|---------|-------|
| 负债率 | 农牧行业普遍高负债，需关注资产负债率变化 |
| 现金流 | 持续亏损对经营性现金流的消耗 |
| 资本开支 | 在建工程及产能扩张的资金需求 |
| 资产减值 | 猪价低位下的生物资产减值风险 |

## 9. 总结

### 核心结论

**新希望是一家兼具防御性与弹性的农牧龙头。** 饲料业务作为现金牛提供稳定的安全垫（年盈利11-15亿），养殖业务则赋予公司极高的猪周期弹性。当前公司正经历猪周期底部的阵痛期，2025年全年亏损17.84亿，2026年上半年预亏16-18亿，但核心亮点在于养殖成本持续快速下降（从12.84元/kg降至12.22元/kg，目标年底11.22元/kg）。

### 投资逻辑梳理

| 维度 | 判断 |
|------|------|
| **安全边际** | 1.69倍PB处于历史中低位，饲料业务价值提供底部支撑 |
| **周期位置** | 行业产能持续去化，猪价反转预期渐强 |
| **业绩拐点** | 2026H2有望迎来单季度盈利转正，2027年进入利润释放期 |
| **核心催化剂** | 猪价反弹+成本降至11.22元/kg以下 |
| **主要风险** | 猪价反转延迟、成本下降不及预期、可交换债质押压力 |

### 关键观察指标

1. **月度猪价走势**：能否突破14元/kg并站稳
2. **养殖完全成本**：是否按目标降至11.22元/kg
3. **饲料业务盈利**：增速能否维持20%+
4. **控股股东质押情况**：质押比例是否进一步上升
5. **机构盈利预测修正**：是否出现向上的集体修正

### 一句话总结

> **饲料稳底盘，成本降空间，猪价定弹性。新希望正站在周期底部，等待猪周期反转的东风。** 当前机构分歧极大，恰是投资者需要深度研究、独立判断的关键时刻。
