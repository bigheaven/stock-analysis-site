## 二、银行股的本质：不是成长，是利息

```
银行的商业模式：
├── 吸收存款（付利息给储户）
├── 发放贷款（收利息从借款人）
├── 赚中间的差价（净息差）
└── 净息差 × 贷款规模 = 核心利润

当前困境：
净息差 1.40%（历史最低，2022年是2.09%）
→ 意味着每放100块贷款，银行只赚1块4的差价
→ 而不良贷款率是1.51%
→ 赚的比可能亏的还少
→ 这就是"净息差与不良率倒挂"
```

## 三、四大行 vs 招行：两种逻辑

```
四大行（工/建/交）："大而不倒"的红利逻辑
├── 系统重要性银行，国家信用背书
├── 利润几乎为零增长（1-3%），但分红稳定
├── 净息差极薄（1.3-1.5%），靠规模吃饭
├── PB 0.5-0.6x → 市场认为净资产里有"水分"
├── 股息率 5-6% → 全市场最接近国债的股票
└── 保险和汇金在买 → 不是看好增长，是需要配置

招行："零售之王"的品质逻辑
├── 零售存款占比高 → 资金成本低 → 净息差远高于大行
├── 财富管理中收强 → 不纯靠吃利差
├── ROE 14%+ → 大行只有10%
├── PB 0.9x+ → 市场给溢价，但也意味着跌得更多
├── 股息率 3.5% → 比大行低，但增长更好
└── 如果银行股回暖，招行弹性最大
```

## 四、股息率可持续吗？

| | 支撑 | 压力 |
|---|---|---|
| **工行/建行/交行** | 汇金+险资持续增持；政府注资5000亿补充资本；分红30-32%极保守 | 净息差还在跌(Q1 1.40%)；不良双升；利润增长几乎为零 |
| **招行** | ROE 14%最强；零售成本优势；财富管理增长 | 不良在上升；房地产仍有敞口；估值比大行贵 |

**银行股分红最不可能被砍——** 因为它们的股东就是国家。汇金、财政部、社保基金每年靠银行分红过日子，砍了分红等于砍了自己的收入。

## 六、底线

银行股是A股里**最无聊、最可靠、最像定期存款**的收息标的。它们不会翻倍，不会涨停，不会出现在热搜——但每年5-6%的分红会准时到账，像发工资一样。这轮2026年银行股的上涨不是基本面驱动的，是险资和汇金在低利率时代找不到更好资产，被迫配置的。

如果你定投中车是"稳"，那定投工行是"更稳"。代价是：中车还有维保增长的故事，银行连故事都没有。

## 七、银行股五次危机史

每次银行大跌，原因不同，结局惊人一致——政策出手兜底，恐慌消退，银行活了下来。

| 时间 | 危机 | 触发 | 最低PB | 结局 |
|------|------|------|--------|------|
| 2008 | 次贷危机 | 中资银行持有次贷资产 | — | 全球救市，四万亿出台 |
| 2010-2012 | 地方债危机 | 4万亿后城投疯狂举债，审计曝10.7万亿 | <1x | 债务置换化解 |
| 2013 | 钱荒 | 央行主动收紧，隔夜利率飙到30% | — | 政策制造的流动性恐慌 |
| 2018-2019 | 去杠杆+包商银行 | 影子银行清理+包商被接管 | 0.7x | 央行接管包商，储户全额赔付 |
| **2021-2022** | **房地产暴雷** | 恒大→碧桂园→华夏幸福连环炸 | **0.4x（历史最低）** | 化债+5000亿注资+政策兜底 |

### 2022年底：为什么是底？

```
2022年工行股价~4元，PB 0.4x，股息率~7.5%

市场在定价："银行的净资产里全是烂尾楼坏账，水分巨大"
实际情况：对公房地产贷款只占银行总贷款的5%

2023-2026年涨了80%，利润只涨了2%
→ 涨的不是基本面，是恐慌消退带来的PB修复（0.4→0.6x）

这轮修复的五大驱动力：
1. 化债（10万亿+）→ 城投贷款不再恐慌
2. 房地产没崩盘 → 对公贷款5%，影响有限
3. 政府注资5000亿 → "国家不会让大行出事"
4. 险资被挤出债市 → 只能买银行股当高息债
5. 汇金无限托底 → 通过ETF持续买入

所以2026年4%的股息率，
和2022年7.5%的股息率，
买的是同一个东西，
只是恐慌溢价消失了。
```

**规律**：银行的"周期"本质上是"恐惧→修复"的情绪钟摆。在PB最低、股息率最高、市场最恐慌时买，赚的不只是分红，还有恐慌退潮时的估值修复。现在PB已经修复到0.6x，最肥的那段已经过去了——剩下的只有每年4%的分红。
