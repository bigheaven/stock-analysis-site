## 一、一句话定位

**中国最大综合金融集团，保险+银行+资管+科技四轮驱动。A股沪深300权重第三（仅次于茅台、宁德），每轮牛市都有它的影子——不是因为它涨得多，而是因为国家队护盘必拉它、外资回流必配它、基金低配回归必买它。PE 6.9x、PB 0.93x、股息率5.3%连续14年增长。更像是"金融债券"而非普通股票。**

## 三、它是周期股吗？

用你的周期光谱框架打分：

| 指标 | 状态 | 判定 |
|------|------|------|
| **渗透率** | 保险深度中国~4%（发达国家~8%） | 🟢 还有成长空间 |
| **CAPEX/资产** | 轻资产（保险是浮存金生意）| 🟢 非重资产周期 |
| **壁垒** | 2.51亿客户、全牌照、综合金融生态 | 🟢 极深护城河 |

**判定：非传统周期股，是"金融周期股"。** 驱动力不是供需错配，而是**利率+权益市场+政策**三重周期：

```
平安的"周期"来自三个放大器：

1. 利率周期 → 利率下行=固收收益缩水=利差损风险
2. 权益市场 → 6.5万亿投资资产，股市涨则利润暴增、跌则利润暴降
3. 政策周期 → 保险监管、会计准则切换、地产调控

→ 它不是"行业景不景气"的周期
→ 它是"利率高不高、股市好不好、监管严不严"的周期
→ 所以每轮牛市它都在——因为牛市=股市涨+利率通常回升
```

## 四、为什么每轮牛市都有它的影子？

```
2007 估值牛 → 平安太保国寿同涨，金融股是主线
2015 杠杆牛 → 金融蓝筹补涨，国家队护盘首选
2021 抱团牛 → 核心资产行列，外资配置必选
2026 AI牛   → 沪深300权重第三，基金低配修复逻辑

平安的"牛市角色"：

1. 沪深300权重第三 → 指数基金被动配置
2. 国家队护盘第一梯队 → 每次救市先拉金融
3. 外资回流中国 → 流动性好+估值低+够大 → 首选
4. 公募低配回归 → 2025Q4持仓仅1.06%，历史低位，有回归空间

它从不"领涨"——领涨的是AI/半导体/新能源。
但它每次都在"跟涨"——当牛市进入中后段，
资金从高估值流向低估值时，平安就是那个"接水的水池"。
```

## 五、为什么"默默无闻但打不死"？

```
"默默无闻"的原因：
├── 保险股 = 难懂（内含价值/新业务价值/营运利润...概念太多）
├── 没有AI/机器人/新能源那样的故事性
├── 增速不快（6-10%），不是吹泡泡的料
└── 市值太大（9000亿+），没人能"炒"得动

"打不死"的原因：
├── 2.51亿客户（留存率99%）→ 每天都在收保费
├── 全牌照（保险+银行+资管+科技+医疗）→ 东方不亮西方亮
├── 6.5万亿投资资产 → 中国金融体系的"影子央行"
├── 连续14年分红增长 → 不画饼，真分钱
└── PE 6.9x + PB 0.93x → 便宜到很难再跌多少
```

## 六、股息率能持续吗？

| ✅ 支撑 | ⚠️ 压力 |
|---------|---------|
| 连续14年增长，管理层分红意愿强 | 2026Q1净利-7.4%，全年能否维持分红增幅？ |
| 派息率42%，合理且可持续 | 利率持续下行→固收收益缩水→利差损风险 |
| 新业务价值(NBV)高增:+29%(2025),+21%(2026Q1) | 代理人从35.1万降至33.2万，渠道在萎缩 |
| OPAT稳健增长+10.3%→分红来源稳定 | Q1投资收益率骤降0.2%→股市波动直接影响利润 |

**最坏情景推演**：股市暴跌30% + 利率再下50bp → 平安利润可能腰斩 → 但派息率42%的缓冲空间大，每股分红有可能不降（动用留存利润），降幅大概率远小于中车和中铁。

## 七、最大的风险：三颗雷

### 雷1：利差损（最危险的慢性病）

```
平安的商业模式本质是：
向客户收保费（承诺2-3%的回报率）
→ 把这笔钱投出去（买债券+股票）
→ 赚差价

当前困境：
负债端成本 ~2.76%（存量保单的隐含承诺）
资产端收益 ~3.7%（净投资收益率）
→ 利差不到1%，而且利率还在降
→ 日本1990年代的保险业危机就是这么来的
```

### 雷2：华夏幸福（已经炸过、基本清理了）

```
2018-2021：累计投入 ~540亿
2021：计提 432亿损失
2025H1：剩余敞口仅 ~5.1亿股权 + 部分债权
→ 占总投资资产 0.1%
→ 已经在大量减持华夏幸福股份

教训惨重，但基本已出清。
```

### 雷3：权益市场波动（当前最直接的风险）

```
2025年大幅增配了二级权益（仓位从~10%提到~12.6%）
→ 2026Q1投资收益率从1.3%骤降至0.2%
→ 利润立即受冲击（Q1净利-7.4%）

如果2026H2熊市来临 → 利润可能大幅缩水
但平安的"OCI股票"占比60%+ → 很大一部分浮亏不进利润表
```

## 八、什么时候值得买？

```
✅ 适合：
├── 想收股息 → 5.3%+14年增长记录
├── 赌牛市后半段 → 资金从AI切回低估值时，平安会涨
├── 做防守配置 → PE 6.9x、PB 0.93x，下行空间有限
└── 相信中国保险渗透率会翻倍（目前4% vs 发达国家8%）

❌ 不适合：
├── 追求高弹性 → 年涨20%是上限，不会翻倍
├── 担心利率长期下行 → 这是平安的命门
└── 无法接受季度利润波动 → 股市每季都在影响它的利润
```
