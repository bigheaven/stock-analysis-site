### 为什么会这样？

| 阶段 | PE | 发生了什么 |
|------|-----|-----------|
| 发行价 10.11 | ~22x | 合理区间，与行业均值匹配 |
| 首日收盘 23.95 | ~51x | 深市最大IPO光环+新股情绪+央企标签 → 严重透支 |
| 最高 28.08 | ~57x | 泡沫顶峰，隐含"利润不再下滑+绿电溢价"双重乐观假设 |

**核心教训**：首日 PE 57x 给一个利润三年连降的公司，本身就是定价错误。回归是必然的。

## 二、利润下滑三步拆解

```
归母净利润走势：
2023 ──── 82.80亿 (+31.5%)  ← 补贴黄金时代的尾声
2024 ──── 79.53亿 (-4.0%)   ← 补贴退坡+电价松动
2025 ──── 61.02亿 (-23.3%)  ← 电价+利用小时双杀
2026H1E ─ 33-38亿 (-19~-30%) ← 加速下滑

三年蒸发 21.78亿（-26.3%）
```

### 三刀同时砍下来

| 刀 | 怎么砍的 | 数据 |
|----|----------|------|
| **电价刀** | 市场化交易占比提升→电价从补贴价跌向市场价 | 风电0.45→0.35元(-22%)，光伏0.37→0.28元(-24%) |
| **消纳刀** | 电网消纳能力跟不上装机增速→弃电率飙升 | 光伏弃光率1.52%→12.73% |
| **补贴刀** | 财政补贴退坡，确认收入减少 | 补贴收入64.79→39.74亿(-39%) |

**三重叠加** = 装机在涨（+10%以上），但收入几乎不涨（229亿 vs 228亿），而折旧刚性上升 → 利润被双向碾压。

## 三、136号文：绿电行业的历史分水岭

```
136号文（2025.2发布，2026.6.1全面生效）

 改革前                          改革后
 ════════                       ════════
 电价 = 煤电基准价 + 补贴         电价 = 市场竞争形成
 电量 = 电网优先消纳               电量 = 自己找买家
 赚钱 = 躺赢                       赚钱 = 站着竞争

 核心变化：
 ✅ 场外差价结算机制 ← 为投资者留了安全网
    （市场均价<机制电价 → 电网补差额）
 ✅ 取消强制配储 ← 降低投资成本
 ❌ 增量项目各省竞价 ← 电价持续下行压力
 ❌ 补贴彻底退出 ← 存量项目补贴也逐年递减
```

### 对华润的影响矩阵

| | 短期(2026) | 中期(2027-28) | 长期(2029+) |
|---|---|---|---|
| **存量项目** | 机制电价兜底，利润仍有保障 | 保障期逐步到期 | 全面市场化 |
| **增量项目** | 竞价结果分化（广东好/山东差） | 中枢电价明朗 | 优胜劣汰 |
| **华润禀赋** | 利用小时优势+融资成本低 | 跨区调配+储能配套 | 市场份额提升 |

**关键判断**：136号文没有杀死绿电，但它把"躺着赚钱"变成了"站着竞争"。华润作为央企龙头，利用小时高、融资成本低、跨区能力强，在行业分化中会**受益于供给侧出清**——但这需要时间，短期利润阵痛不可避免。

## 四、估值锚定

### 相对估值

| 方法 | 锚 | 对应股价 | 逻辑 |
|------|-----|----------|------|
| 行业PE均值 | 23-25x | **11.0-12.5元** | 回归行业均值 |
| 央企溢价 | 25-28x | **12.5-14.0元** | 运营效率+规模溢价 |
| 发行价锚 | 10.11元 | **~10元** | 机构认可的底部 |
| 当前价 | ~32x | **13.20元** | 仍高于行业均值 |

### 利润敏感性

假设 2026 全年净利 55-60 亿（H1 33-38亿 + H2通常略好）：

| 全年净利 | PE 23x | PE 25x | PE 28x | PE 32x(当前) |
|----------|--------|--------|--------|-------------|
| 55亿 | 9.7元 | 10.6元 | 11.8元 | 13.5元 |
| 60亿 | 10.6元 | 11.5元 | 12.9元 | 14.8元 |
| 65亿 | 11.5元 | 12.5元 | 14.0元 | 16.0元 |

> 当前股价(~13.2元)隐含全年净利~60亿 + PE 28x，或 55亿 + PE 32x。在利润仍在下滑的背景下，偏乐观。

## 五、与锂业的周期对比

| | 锂业（赣锋/天齐） | 绿电（华润新能源） |
|---|---|---|
| **周期类型** | 库存周期（3-5年） | 资产周期（20年电站折旧）|
| **波动烈度** | 极高（价格可翻倍/腰斩） | 平缓（电价变动±20%）|
| **底部特征** | 行业普遍亏损→产能出清 | 利润持续压缩但不太会亏 |
| **顶部特征** | 暴利→全行业疯狂扩产 | 补贴黄金期已过，不会重现 |
| **投资逻辑** | 择时（赌周期反转） | 择价（PE跌到多少算便宜） |
| **核心变量** | 碳酸锂价格/库存/CAPEX | 电价/利用小时/补贴回款 |
| **出清信号** | 高成本矿停产 | 小运营商卖资产给央企 |
| **最危险时刻** | PE最低时（利润峰值） | PE看似低但利润还在跌 |

**一句话**：锂业赚的是"别人亏钱我抄底"的钱；绿电赚的是"等利润跌透了，用低PE买稳定现金流"的钱。

## 六、什么时候见底？

```
三个信号，至少要看到两个：

信号1：利润降幅收窄
  → 2026H2 vs H1，如果H2降幅<15%，说明Q3-Q4企稳
  → 观察窗口：2026年报（2027.3）

信号2：电价不再跌
  → 各省月度竞价结果环比不再下降
  → 绿电交易溢价开始形成第二收入来源
  → 观察窗口：每月的电力交易数据

信号3：补贴开始回
  → 195亿应收款出现实质性回收
  → 观察窗口：季报现金流量表

最可能的时间窗口：
  → 2026年报（2027.3）：首次验证"下滑是否见底"
  → 2027H1：增量项目竞价全部结束，电价中枢可测算
```
