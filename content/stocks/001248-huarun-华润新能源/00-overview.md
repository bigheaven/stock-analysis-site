## 一、一句话定位

**华润集团旗下唯一风光发电平台，国内第四大新能源运营商。2026年7月深交所史上最大IPO（245亿），首日暴涨137%后15个交易日腰斩。利润三年连降（82.8→61.0亿），正处于从"补贴驱动"向"市场驱动"的转型阵痛期。**

## 二、业务结构

```
2025年收入构成：229.09亿

风力发电    184.80亿 (82.4%)  ← 绝对主力
太阳能发电   39.51亿 (17.6%)  ← 快速增长(2023年仅7.6%)
储能+其他     4.78亿           ← 新增长点

装机结构：4158.99万千瓦
风电  2763.07万千瓦 (66.4%)  占全国4.32%
光伏  1395.92万千瓦 (33.6%)  占全国1.16%
```

## 四、周期光谱定位

用 [[cycle-growth-spectrum-framework-周期光谱框架]] 三指标打分：

| 指标 | 状态 | 判定 |
|------|------|------|
| **渗透率** | 风电9%/光伏7%（发电量占比） | 🟢 还在成长早期 |
| **CAPEX/资产** | 极度重资产，在建工程>营收 | 🔴 周期股特征 |
| **壁垒** | 资本+规模（央企优势），技术壁垒为零 | ⚠️ 可被钱复制 |

**综合判定**：**成长型周期股**。装机在涨（成长），但每度电赚的钱在跌（周期）。核心矛盾不是"能不能长大"，而是"长大的同时利润率跌到哪里才止住"。

## 六、核心矛盾：越建越亏的死循环？

```
装机增长 → 固定成本↑（折旧） → 需要更多收入覆盖
                ↕
电价下跌 ← 市场化竞价 ← 全行业都在建
    ↕
补贴退坡 → 收入↓ → 利润不断被压缩
    ↕
应收补贴195亿挂账 → 现金流紧张 → 再融资建更多？
```

**打破循环的关键**：电价企稳 + 补贴回款 + 储能/绿证等新收入来源。

## 七、主要风险

1. **电价继续下行**：136号文后各省竞价，增量项目电价可能更低
2. **应收补贴**：195亿（占流动资产64%），回款周期320天+
3. **弃风弃光恶化**：光伏弃光率已从1.52%升至12.73%
4. **海上风电不确定性**：300.6万千瓦新项目集中于2026-27开工，投资回报不确定
5. **散户踩踏**：首日换手率68%，高位接盘的散户解套压力大
