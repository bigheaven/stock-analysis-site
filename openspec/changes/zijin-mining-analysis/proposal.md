# 紫金矿业(601899) 深度分析

## 为什么做这个分析

用户从抖音短视频文案中发现紫金矿业的投资价值，要求结合公开信息进行深度分析。紫金矿业是全球最大的黄金生产商、亚洲最大的铜生产商，同时布局锂矿，属于"金铜锂三线共振"的稀缺标的。

## 分析范围

- 利润结构拆解（贸易vs矿山、金vs铜vs锂）
- 财务表现（2025年报+2026Q1）
- 核心壁垒（成本优势、海外并购、资源禀赋）
- 锂业务第二增长曲线
- 周期敏感度（金价/铜价/锂价弹性）
- 估值分析（同业对比+SOTP）
- 主要风险

## 数据来源
- 公司2025年报、2026年一季报
- 公开网络研报（雪球、东方财富等）
- 抖音短视频文案交叉验证
