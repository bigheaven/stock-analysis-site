# 需求规格

## 功能需求

| ID | 需求 | 优先级 | 说明 |
|----|------|--------|------|
| F-01 | 三家公司业务结构对比 | P0 | 收入/利润按业务板块拆分，占比可视化 |
| F-02 | 近3年财务数据对比 | P0 | 营收、净利润、毛利率、ROE、负债率等关键指标 |
| F-03 | 猪周期敏感度分析 | P0 | 猪价变动对不同公司利润影响的量化弹性 |
| F-04 | 核心竞争壁垒评估 | P0 | 每家公司的不可复制优势梳理 |
| F-05 | 2026-2028年业绩预测 | P0 | 基于机构一致预期的盈利预测汇总 |
| F-06 | 风险因素清单 | P0 | 每家公司3-5个核心风险 |
| F-07 | 估值对比 | P1 | PE/PB/头均市值/股息率等指标横向对比 |
| F-08 | 投资场景推荐 | P1 | 不同市场情景下的最优选择 |

## 非功能需求

| ID | 需求 | 说明 |
|----|------|------|
| NF-01 | 数据时效性 | 财务数据基于最新披露（2025年报+2026Q1+2026H1预告） |
| NF-02 | 数据可追溯 | 所有数据标注来源，关键数据引用原始财报 |
| NF-03 | 结构清晰 | 使用表格+图表+要点形式，便于快速阅读 |
| NF-04 | 免责声明 | 明确标注不构成投资建议 |
