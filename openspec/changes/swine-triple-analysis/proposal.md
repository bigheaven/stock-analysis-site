# 猪肉产业链三巨头对比分析

## 为什么做这个分析

猪肉产业链是 A 股消费/周期板块的核心赛道，涉及**养殖、屠宰加工、饲料**三个环节。双汇发展（000895）、牧原股份（002714）、新希望（000876）分别代表三个环节的龙头，但三者业务模式、周期敏感度、投资逻辑截然不同。

当前（2026年7月）猪价处于周期底部，能繁母猪存栏已连续10个月去化，市场对猪价拐点预期升温。在这个时间点做三家公司系统对比，有助于：

1. 理清三者在产业链中的定位差异
2. 量化猪周期对各家的影响弹性
3. 识别各自的核心壁垒与风险
4. 为投资决策提供结构化参考

## 分析范围

### 标的
- 双汇发展（000895.SZ）— 屠宰+肉制品加工龙头
- 牧原股份（002714.SZ）— 生猪养殖龙头
- 新希望（000876.SZ）— 饲料+养殖龙头

### 分析维度
1. **业务结构与盈利模式** — 各业务板块收入/利润占比，盈利驱动因素
2. **财务健康度** — 营收趋势、利润水平、资产负债结构、现金流、分红
3. **猪周期敏感度** — 猪价变动对各公司利润的影响弹性
4. **核心竞争壁垒** — 品牌、成本、技术、规模等不可复制优势
5. **2026-2028年业绩展望** — 基于机构一致预期的盈利预测
6. **主要风险因素** — 各自面临的特有风险
7. **估值对比** — PE/PB/头均市值等估值指标

### 数据来源
- 2025年年报、2026年一季报、2026年半年度业绩预告
- 券商研报一致预期数据
- 行业公开数据（能繁母猪存栏、猪价、出栏量等）
