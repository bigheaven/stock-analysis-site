### 每家公司分析模板

```
1. 公司概览
   - 业务结构（收入/利润占比饼图）
   - 产业链定位
   - 行业地位

2. 财务分析
   - 近3年营收/利润趋势
   - 盈利能力（毛利率、净利率、ROE）
   - 资产负债结构
   - 现金流质量
   - 分红政策

3. 核心壁垒
   - 3-5个不可复制优势
   - 量化对比（如有）

4. 猪周期敏感度
   - 猪价弹性测算
   - 不同猪价情景下的利润模拟

5. 业绩展望
   - 2026-2028年机构一致预期
   - 关键假设与分歧点

6. 风险因素
   - 特有风险
   - 行业共性风险
```

### 横向对比维度

| 对比维度 | 呈现方式 |
|----------|----------|
| 业务结构 | 表格 + 堆叠柱状图 |
| 财务指标 | 对比表格 + 雷达图 |
| 猪周期弹性 | 敏感性分析表 |
| 估值 | PE/PB Band 对比 |
| 风险 | 风险矩阵图 |

## 数据来源策略

| 数据类型 | 来源 | 获取方式 |
|----------|------|----------|
| 财务数据 | 公司年报/季报 | 公开财报、新浪财经 |
| 业绩预测 | 券商研报 | 机构一致预期数据 |
| 行业数据 | 统计局/农业农村部 | 公开数据 |
| 股价/估值 | 行情数据 | 雪球/东方财富 |

## 技术方案

- 产出格式：Markdown 文档（存放在 `content/stocks/` 目录下）
- 图表：使用 Markdown 表格 + 文字描述
- 版本管理：纳入现有 git 仓库
